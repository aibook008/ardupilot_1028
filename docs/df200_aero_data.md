## 1. 坐标系与符号约定

### 1.1 三坐标系（sheet「坐标系和方向」原文摘要）

| 系 | 原点 | 轴向 |
|---|---|---|
| 机体系 (b) | 质心 | Xb 指向机头，Yb 右，Zb 下 |
| 气流系 (W) | 质心 | Xw 沿相对气流**指向前**，Zw 垂直速度矢量指向下，Yw 右 |
| 结构系 (S) | 机头参考点 | **Xs、Zs 与机体系相反**，Ys 与机体一致（即 X 后、Y 右、Z 上） |

### 1.2 关键口径声明（sheet 原文）

> 力系数（CD、CL、CY）在**气流坐标系**下，CL 正值取 OwZw 负向、CD 正值取 OwXw 负向；
> 力矩系数（Cl、Cm、Cn）在**机体坐标系**下；
> 重心、旋翼位置、气动焦点在**结构坐标系**下。

### 1.3 舵偏正方向定义（sheet 原文）

| 舵面 | 正偏转角 (δ>0) | 产生的力矩（机体系） |
|---|---|---|
| 升降舵 δe | 左翼后缘向左（下）、右翼后缘向右（下） | **低头**（−My） |
| 副翼 δa | 左翼后缘向上、右翼后缘向下 | **负滚转**（左滚，−Mx） |
| 方向舵 δr | 左翼后缘向左（下）、右翼后缘向左（上） | **负偏航**（左偏，−Mz） |

### 1.4 符号表

力：L 升力 / D 阻力 / Y 侧力 / T 推力；力矩：Mx 滚转 / My 俯仰 / Mz 偏航 / Q 扭矩；
系数：CD CL CY Cl Cm Cn；角：α 迎角 / β 侧滑角；角速度：p q r（+ α̇ β̇）。

## 5. 气动数据

### 5.0 工况与无量纲化

全部气动表在**单一工况**给出：V=48.611 m/s（175 km/h）、ρ=1.225、H=200 m。动压：

```text
q = ½·ρ·V² = 0.5 × 1.225 × 48.611² = 1446.9 Pa
qS = 1446.9 × 5.28846 = 7652.3 N
```

**网格**：α ∈ {−4, −2, −1, 0, 1, 2, 4, 6, 8, 10, 12, 14}°（12 行），β ∈ {−15, −10, −5, −3, −1, 0, 1, 3, 5, 10, 15}°（11 列）。
系数表给出 6 个无量纲系数（CD CL CY Cl Cm Cn），其下还并排给出对应的**有量纲力/力矩表**（D L Y Mx My Mz，单位 N / N·m），力表 = 系数 × qS（抽样验证：CD(0,0)=0.0327931 × 7652.3 = 251.0 N = D 表值 ✓）。本文只录系数表，力/力矩表省略（可由 qS 换算）。

**数据对称性说明**：网格在 α 上不对称（−4 有 +4、−2 有 +2、但 −1/+1、0 无负对），β 近似对称但非严格（数值微差为 CFD 网格/求解噪声，如 CD(0,+15)=0.06076 vs (0,−15)=0.06076 对称良好；CY 在 β=0 处不为精确 0，残差 ~1e-4 量级，可接受）。

## 7. 已知局限与待确认问题（汇总，发数据库方）
