## 1 为什么要单独 catch-up

总计划里转换安全已写 ABORT / 空速门槛，但：

1. **完整走廊 ≠ 现有门槛**（见对照分析）：缺 V_min/max(θ)、事前限幅、可选中线调度。  
2. **300kg + 协议转换安全**对「大倾转 + 低空速」更敏感，只靠事后 ABORT 偏晚。  
3. **气动数据是外部依赖**：不单独立项容易拖到试飞前才发现「没表、没用例、没处置」。  

本计划把走廊从「认知缺口」变成**有出口的工作包**，与总计划并行，不推翻一期文档结构。

## 2 目标与非目标

### 2.1 目标（验证机转换首飞前，约三期 W11 前）

| ID | 目标 | 可验证出口 |
|----|------|------------|
| T1 | 具备可用的 V_min(σ)/V_max(σ)（正式气动或分段工程近似） | 特性分析走廊表 V1.0 |
| T2 | 运行时监视 (σ, V_a) 与出界事件 | 日志/遥测可见；SIM-COR-01 通过 |
| T3 | 出界处置与现有 ABORT/限倾转/限油门联动 | SIM-COR-02/03 通过 |
| T4 | 仿真用例与出门准则纳入仿真计划 | `07` 增 SIM-COR-*；二期/三期报告引用 |
| T5 | 对甲控制律/特性分析升版写清「一期近似 + 走廊增强」 | phase1 `05`/`06` 脱敏升版 |

### 2.2 非目标（本 catch-up 不承诺）

- 不在本计划内承诺自研完整最优转换轨迹规划器  
- 不以修改上游 APM 合入为主线（实现可在项目分支/配置层；文档 catch-up 与实现可分期）  
- 不等待完美风洞再开始：允许分段常数表启动监视与仿真  

### 2.3 成功标准（最小）

同时满足：

1. 转换仿真中可复现「故意穿出 V_min 带 → 禁止继续倾转或 ABORT」；  
2. 正常转换轨迹在走廊内（或贴中线）可从日志证明；  
3. 对甲材料不再暗示「仅有全局空速门槛即等于走廊」。

## 4 分期节奏（Catch-up 专用时间表）

> 周次与总计划 W3–W11 对齐；可按气动数据到达日整体平移，但 **C1–C3 不因数据缺失而停**（用近似表）。

### Phase C0（立即～一期结束，~08-31）

| 项 | 动作 |
|----|------|
| 文档 | 本分析 + 本计划入库；开放问题 C-01~C-04 进周报 |
| 数据 | 发出气动走廊数据索取；并行起草三段近似表 |
| 对甲 | 不夸大；评审口吻准备「门槛近似 + 增强项」 |

**C0 出口**：分析+计划评审通过；近似表 v0 有人维护。

### Phase C1（二期 W3–W5，~09-01～09-20）— 设计与仿真骨架

| 周 | 动作 | 出口 |
|----|------|------|
| W3 | A3 近似表；B1 监视器设计；`07` 草稿 SIM-COR-* | 设计评审 |
| W4 | B2 处置与 ABORT 优先级；B4 开始改 `05`/`06` | 控制律增强节草稿 |

**C1 出口**：监视+穿下限处置在仿真可演示；文档脱敏段落可评审。

### Phase C2（二期 W6～三期 W8，~09-21～10-11）— 闭环与策略冻结

## 7 风险与缓解

| 风险 | 缓解 |
|------|------|
| 气动数据长期不到 | 分段近似表 + 仿真仍做 C1–C3；报告声明置信度 |
| 走廊与现有 ABORT 双重触发打架 | A4 明确优先级：走廊下限可先限 σ，持续再 ABORT |
| 实现排期挤占 ABORT 主路径 | **ABORT 主路径不让路**；走廊监视可先做、处置后开 |
| 对甲误解「已有走廊」 | 统一口径见对照分析 §7；评审用幻灯一页讲清 |
