## 1 文档说明

### 1.1 变更控制

1. 任何针脚、波特率、消息 ID、PWM 默认功能变更须提变更单。  
2. 乙方拟制 → 双方接口负责人审核 → 升版本（V0.9→V1.0 冻结后变更需双方签字）。  
3. 已装机线缆以本 ICD 版本号标识。

### 1.2 版本策略

- **V0.9**：一期，物理接口与通道规划冻结；CAN 消息全集可二期补全。  
- **V1.0**：二期 HIL 前，电气实测确认。

## 2 电气与机械接口

### 2.1 供电

| 项 | 规格（基线，随选定板型微调） |
|----|------------------------------|
| 标称输入 | 5 V 伺服轨 + 独立飞控电源（或板型规定的 4.9–5.5 V） |
| 机载高压 | 经低压适配模块降至飞控允许范围（交付适配模块） |
| 反接/过压 | 板载或外置保护，要求写入到货验收 |
| 地 | 信号地与动力地单点或按厂商手册连接；禁止舵机回流经信号地 |

### 2.2 连接器与针脚

> 具体连接器型号随选定飞控计算机固化。下表为**逻辑端口分配**，装机图单独出图册。

| 逻辑端口 | 功能 | 电气类型 | 备注 |
|----------|------|----------|------|
| PWR_IN | 飞控主电 | 电源 | 经适配模块 |
| CAN1 | 航电/电调总线 A | 隔离 CAN | 120Ω 终端按拓扑 |
| CAN2 | 航电/电调总线 B 或余度 | 隔离 CAN | |
| GPS1 | 主 GNSS | UART | |
| GPS2 | 备 GNSS / RTK | UART | |
| TELEM1 | 主数传 | UART | |
| TELEM2 | 备数传 | UART | |
| RC | 遥控接收 | UART/SBUS/CRSF 等 | 以接收机为准 |
| ADS / RID | 空速或 Remote ID | UART/CAN | 可复用空闲口 |
| DEBUG | 维护口 | USB/UART | 地面用 |
| SD | 日志卡 | SDIO | 工业卡 |
| PWM_BANK | 作动输出 | PWM | 见 §3.3 |

### 2.3 机械

| 项 | 要求 |
|----|------|
| 安装 | 减震座；轴向按厂商 IMU 指向约定（X 前 Y 右 Z 下，或书面约定） |
| 重量 | 计算机整套 ≤2 kg |
| 外形 | 以厂家 ICD 图纸为准，附录附安装孔图 |

## 3 数字总线接口

### 3.1 CAN（≥2 路隔离）

| 项 | 基线 |
|----|------|
| 波特率 | 1 Mbit/s（可配置 500 k；全机统一） |
| 终端 | 总线两端 120 Ω |
| 节点规划 | 飞控=最高优先级节点；电调、舵机、传感器分区 ID |
| 应用层 | DroneCAN/同类航电 CAN（具体 DSDL 二期出消息表） |

**一期消息框架（示例类）**

| 类 | 方向 | 内容 |
|----|------|------|
| 电调状态 | 外→飞控 | 转速、电流、故障字 |
| 电调指令 | 飞控→外 | 油门、使能 |
| 空速/GNSS（若 CAN） | 外→飞控 | 校准量 |
| 健康心跳 | 双向 | 节点存活 |

### 3.2 UART（≥5 路）

| 端口逻辑名 | 默认用途 | 默认波特率 | 协议 | 流控 |
|------------|----------|------------|------|------|
| UART_GPS1 | 主 GNSS | 230400 | GNSS 二进制/NMEA | 无 |
| UART_GPS2 | 备 GNSS/RTK | 230400 | 同上 | 无 |
| UART_TELEM1 | 主数传 | 57600/921600 | 地面站协议 | 可选 |
| UART_TELEM2 | 备数传 | 57600 | 地面站协议 | 可选 |
| UART_RC | 遥控 | 视接收机 | SBUS/CRSF/PPM | — |
| UART_AUX | 空速/RID/调试 | 115200 | 按外设 | 无 |

> 实际引脚号在选定板型后填入附录 A；波特率以联调锁定为准并升 ICD 版本。

### 3.3 PWM / DI / DO

**通道功能映射（倾转旋翼典型，可配置）**

| 通道逻辑号 | 默认功能 | 脉宽中立 | 刷新率 | 故障默认 |
|------------|----------|----------|--------|----------|
| CH1–CH4 | 旋翼/倾转电机 1–4 | 电调协议规定 | ≥400 Hz（DShot 若用则按协议） | 上锁切断 |
| CH5 | 倾转舵机总通道或左 | 1500 us | 50–100 Hz | 保持或回垂直（可配置，试飞前冻结） |
| CH6 | 倾转舵机右 | 1500 us | 50–100 Hz | 同上 |
| CH7 | 副翼 | 1500 us | 50 Hz | 中立 |
| CH8 | 升降 | 1500 us | 50 Hz | 中立 |
| CH9 | 方向 | 1500 us | 50 Hz | 中立 |
| CH10 | 油门（固定翼推力）/襟翼 | 视构型 | 50 Hz | 怠速/中立 |
| CH11+ | 扩展（起落架、舱盖等） | — | — | 安全位 |

**倾转行程约定（逻辑）**

| 逻辑倾转 | 含义 |
|----------|------|
| 0% | 旋翼垂直（升力） |
| 100% | 水平前飞 |
| 速率 | 由参数 TR_TILT_RATE_* 限制，不作机械冲击 |

DI/DO：解锁指示、蜂鸣、外部灭火等按任务机定义，不少于协议“4 DI/DO”能力。

## 4 通信协议接口

### 4.1 地面站链路

| 项 | 基线 |
|----|------|
| 会话 | 心跳、时间同步 |
| 参数 | 读写、导出导入 |
| 任务 | 航点上传下载 |
| 遥测 | 姿态、位置、模式、电池、倾转角、转换状态 |
| 日志 | 列表、下载 |
| 指令 | 模式切换、解锁上锁、引导点（权限分级） |

具体消息集与地面站源码一同交付；一期保证与主流地面站协议兼容以便联调。

### 4.2 带宽预算（设计目标）

| 链路 | 建议 |
|------|------|
| 主数传 | 关键遥测 ≥10 Hz；姿态 ≥10 Hz |
| 日志回放 | 落地后高速下载，不占用飞行关键链路 |

### 4.3 遥控

- 通道最小集：滚转、俯仰、油门、偏航、模式、急停/中断转换、返航  
- 失控帧：接收机失控位优先；超时时间可配置（SRS REQ-F-RC-02）

### 4.4 Remote ID

| 项 | 要求 |
|----|------|
| 广播字段 | 按 GB 46750 及模块能力：识别码、位置、高度、速度、时间戳等 |
| 网络报送 | 蜂窝链路至 UOM；频率符合管理要求 |
| 与飞控 | UART/USB/CAN 状态字；失效→SF 模块 |

字段级表在模块选型确定后作为 ICD 附录 D 发布。

## 5 软件二次开发接口（逻辑 ICD）

### 5.1 状态查询（只读）

| 接口名（逻辑） | 返回 | 单位 | 典型频率 |
|----------------|------|------|----------|
| api_get_attitude | roll,pitch,yaw | deg | 50–100 Hz |
| api_get_position_ned | x,y,z | m | 10–50 Hz |
| api_get_velocity_ned | vx,vy,vz | m/s | 10–50 Hz |
| api_get_airspeed | cas/tas | m/s | 10 Hz |
| api_get_battery | V,A,% | — | 1–5 Hz |
| api_get_mode_armed | mode, armed | enum,bool | 事件+1 Hz |
| api_get_tilt_progress | tilt, progress | 0–1 | 50 Hz |

### 5.2 控制注入

| 接口名（逻辑） | 约束 |
|----------------|------|
| api_set_guided_target | 仅引导模式；围栏与 SF 有效 |
| api_request_mode | 受模式表与保护优先级限制 |
| api_request_transition_abort | 触发 TR ABORT（若在转换中） |

**禁止**：直接写原始电机占空比绕过混控与上锁逻辑。

### 5.3 钩子

| 钩子 | 用途 |
|------|------|
| hook_pre_arm | 附加解锁条件 |
| hook_mode_change | 通知 |
| hook_failsafe | 通知（不可取消强制动作） |

详细 C/C++ 头文件在《二次开发说明》给出；本 ICD 管语义与安全边界。

## 6 仿真接口

### 6.1 SITL

| 交换 | 内容 |
|------|------|
| 模型→飞控 | 加速度、陀螺、磁、气压、GPS、空速、转速反馈（可选） |
| 飞控→模型 | PWM/归一化作动、解锁 |

### 6.2 HIL / 半实物

| 项 | 约定 |
|----|------|
| 物理连接 | 按 §2 线缆；或专用 HIL 线束 |
| 时序 | 控制环实时；允许的最大模型步长在仿真计划中规定 |
| 真件范围 | 飞控必真；舵机可选真/假 |

### 6.3 外部高保真模型（MATLAB 等）

| 项 | 基线 |
|----|------|
| 传输 | UDP 或本地 JSON/二进制帧 |
| 字段 | 时间戳、作动、状态、风、故障注入字 |
| 版本 | 模型版本号进入仿真报告 |

字段表二期随联合仿真联调锁定，升 ICD。
