## 1 系统上电后怎么跑起来

### 1.1 启动顺序（逻辑）

```
上电 / 复位
  → HAL/BSP：时钟、总线、PWM、存储、看门狗
  → 驱动：传感器枚举与自检、遥控/数传口打开
  → 参数从非易失存储加载
  → 估计器初始化（未对齐前禁止解锁）
  → 调度器挂接任务表，进入主循环
  → 通信任务开始发心跳；地面站可见“未解锁”
```

**联调检查点 S0**：地面站收到心跳与姿态（即使未解锁）；日志开始写入；错误传感器在解锁检查里可见。

### 1.2 主循环节拍（核心机制）

采用 **单进程、单主循环**：

1. **等待惯性器件新采样就绪**（主节拍锚点，保证“采到的惯性和本拍控制”对齐）。  
2. **tick +1**，扫描任务表。  
3. 对每个任务：若距上次运行的 tick 数 ≥（主频 / 任务目标频率）的整数分频，则执行；否则跳过。  
4. 每个任务有 **时间预算**；超时记健康/日志，由看门狗兜底防死循环。  

| 量 | 设计取值（可配） | 联调时怎么确认 |
|----|------------------|----------------|
| 主循环频率 | 100–400 Hz（大飞机可取偏低端） | 日志时间戳间隔；HIL 统计 |
| 姿态/角速率相关 | 与主循环同量级或高分频 | 内环日志率 |
| 位置/高度外环 | 约 50–100 Hz | 外环日志率 |
| 固定翼导引/能量 | 约 50 Hz | 导航日志率 |
| GPS | 5–10 Hz | GPS 更新计数 |
| 遥测 | 按链路带宽，常见 10 Hz 量级关键量 | GCS 刷新 |
| 保护扫描 | ≥10 Hz | 人为断 RC 的响应时延 |

**要点**：不是“每个模块一个线程”，而是 **一张表 + 分频**；同一 tick 内看到的模式、解锁、导航目标是一致快照，便于复盘。

### 1.3 任务优先级直觉

| 优先级直觉 | 内容 | 说明 |
|------------|------|------|
| 最高 | 等采样、姿态内环、输出刷新相关 | 丢了会抖/失控 |
| 高 | 模式运行、过渡更新、倾转 | 飞行语义 |
| 中 | GPS、电池、罗盘、保护 | 安全与导航 |
| 低 | 日志刷盘、统计、部分 GCS | 可短时拖延，不可饿死过久 |

## 2 一拍之内：数据怎么流

下面按 **“已经解锁、正在飞”** 描述一拍内的逻辑顺序（与调度表声明频率一致，不必每拍每项都跑）。

```
① 惯性/气压/磁等驱动取出本拍校准量
② 状态估计更新 → 姿态、角速度、位置、速度、风、健康度
③ 遥控与地面站指令缓冲合并（模式、杆量、任务）
④ 故障保护扫描（可强制改模式/限幅）
⑤ 当前飞行模式：update（算期望：姿态/速度/航点行为）
⑥ 稳定/控制运行：
     - 若旋翼主导：旋翼串级 → 归一化力矩 + 总推力
     - 若固定翼主导：L1/TECS + 舵面 PID
     - 若转换中：两套都算，再按权重 μ 混合；倾转角 σ 限速推进；推力补偿
⑦ 混控与通道映射 → PWM/CAN 输出队列
⑧ IO 刷新到电调/舵机；日志采样；遥测打包（按各自频率）
```

### 2.1 旋翼主导时（增稳/定高/定点等）

| 步骤 | 输入 | 输出 | 联调时看什么 |
|------|------|------|--------------|
| 模式 | 杆量/位置目标 | 期望角、期望爬升率 | 模式名正确 |
| 角度→角速率→力矩 | 估计姿态/陀螺 | roll/pitch/yaw 力矩 ∈[-1,1] | 拨杆后力矩符号 |
| 高度/油门 | 高度误差 | 总推力 | 油门与高度趋势 |
| 混控 | 力矩+油门 | 各电机推力 | 四轴差动方向 |
| 倾转 | 多在垂直附近 | σ≈0 | 倾转舵机近垂直位 |

### 2.2 固定翼主导时

| 步骤 | 输入 | 输出 | 联调时看什么 |
|------|------|------|--------------|
| L1 | 侧偏/航点 | 期望滚转 | 航线内侧偏收敛 |
| TECS | 高度/空速能量 | 期望俯仰、油门 | 爬升时俯仰与油门分工 |
| 舵面 PID | 姿态误差、空速缩放 | δa/δe/δr | 舵面方向与中立 |
| 倾转 | 前飞位 | σ→1 | 倾转舵机到水平 |

### 2.3 转换中（最容易联调翻车的一段）

同一拍内 **旋翼控制与固定翼控制都可能计算**，输出按混合权重 μ：

| 量 | 含义 | 日志/遥测建议 |
|----|------|----------------|
| σ | 倾转进度 0=垂直 … 1=水平 | 必记 |
| μ | 控制混合 0=纯旋翼 … 1=纯固定翼 | 必记 |
| 阶段 | 等空速 / 计时混合 / 完成 / 中断回退 | 枚举事件 |

```
固定翼侧输出 × μ
旋翼侧输出   × (1-μ)
倾转 σ 按速率限制单独推进（机构物理）
推力再经倾转补偿（如 1/cos 类升力保持）后下发
```

**中断回退（ABORT）**：任一拍保护条件满足 → 阶段切 ABORT → σ 限速回垂直、μ→0、切入旋翼保护模式。联调必须能在台架上用“模拟空速不足/打中断开关”看到该事件。

## 3 飞行模态：谁在发指令

### 3.1 模式生命周期

每个模式三个钩子：

| 钩子 | 做什么 |
|------|--------|
| 进入 | 清积分、设限幅、初始化位置控制器/过渡标志等 |
| 周期运行 | 本拍算出期望（或调用自动子逻辑） |
| 退出 | 交接干净，避免积分带到下一模式 |

切换时记录：**从→到、原因**（遥控、地面站、保护、转换失败、任务航段等）。

### 3.2 模式与控制模块对照（联调用语）

| 逻辑模式 | 飞行员感受 | 本拍主要模块 | 典型联调 |
|----------|------------|--------------|----------|
| 旋翼增稳 | 杆控姿态 | 旋翼角度/速率 + 手动油门 | 台架看电机差动 |
| 旋翼定高 | 杆控水平，高度自动 | 上 + 高度环 | 改变高度目标 |
| 旋翼定点 | 松杆刹停 | 上 + 水平位置环 | GPS 良好时室外 |
| 旋翼起降/返航 | 自动垂直段 | 位置+高度+任务 | 仿真先跑 |
| 固定翼姿态 | 杆控滚转俯仰 | FW 姿态 PID | 看舵面 |
| 巡航/盘旋/航线 | 自动导航 | L1+TECS | 仿真航线 |
| 自动（混合航线） | 一条任务里含垂直与水平段 | 任务引擎按航段类型调用 VTOL 或 FW | 全流程仿真 |
| 保护类 | 返航/降落 | 保护管理器强制模式 | 断遥控试验 |

### 3.3 “是否在 VTOL 控制语义下”

运行中有一个布尔语义（实现名可自定）：**当前是否由多旋翼推力逻辑主导姿态/高度**。  

- 真：走旋翼串级与旋翼混控路径，倾转偏垂直。  
- 假：固定翼路径为主；若仍在转换，则并行跑过渡状态机。  

联调时地面站/日志应能看到该语义或等价模式名，避免“人以为在悬停、机已在转倾转”。

## 4 过渡状态机（运行级）

与控制律文档一致，这里只写 **运行与联调可见行为**：

| 阶段 | 进入条件（概念） | 本拍行为 | 出口 |
|------|------------------|----------|------|
| 空速等待 | 请求转前飞且允许 | μ≈0，旋翼维持；σ 可前倾；等空速≥门槛 | 空速达标→计时；条件失败→ABORT |
| 计时混合 | 空速达标 | μ 0→1（建议 S 曲线）；σ 继续；双控制器混合 | 完成判据→完成；异常→ABORT |
| 完成 | 倾转与空速姿态满足 | μ=1；旋翼关或仅前飞推力 | 切回 VTOL 则反向路径 |
| 中断回退 | 见控制律触发表 | σ 回垂直；μ→0；保护模式 | 稳定旋翼后人工再决策 |

**台架最小演示（不要求上天）**

1. 固定架或卸桨，安全供电。  
2. 注入/模拟空速从低到高，观察阶段与 σ、μ 曲线。  
3. 在空速等待中把空速打回低值或打“中断转换”，必须出现 ABORT 事件与回垂直趋势。  

对应仿真计划用例：SIM-TR-01/02/04。

## 5 作动输出：从归一化到钉子上的线

```
控制律归一化量（力矩/油门/舵面指令）
  → 混控矩阵（电机布局）或舵面映射
  → （转换中）倾转补偿
  → 通道功能表（ICD：CH↔电机/倾转/副翼…）
  → PWM 脉宽 或 CAN 电调帧
  → 电调/舵机
```

| 联调项 | 正确现象 | 错误常见因 |
|--------|----------|------------|
| 电机转向 | 符合混控布局 | 线序、电调反向 |
| 倾转方向 | 0% 垂直、100% 前飞一致 | 舵机行程反、端点未标定 |
| 副翼 | 右滚指令→正确差动 | 通道功能配错 |
| 上锁 | 动力无旋转/安全脉宽 | 解锁检查被绕过 |
| CAN 电调 | 心跳与指令帧计数增加 | 波特率、终端电阻、节点号 |

通道默认表以 **ICD §3.3** 为准；改通道必须升 ICD 版本。

## 6 通信在运行中的位置

通信 **不是** 控制闭环的一环（控制不依赖 GCS 每拍到达），而是：

| 方向 | 内容 | 频率直觉 | 丢了会怎样 |
|------|------|----------|------------|
| 上行（人→机） | 模式、解锁、任务、参数、引导点 | 事件型 | 无法操控/调参；有 RC 仍可能飞 |
| 上行 RC | 杆量、开关 | 高 | 触发 RC 失控保护 |
| 下行 | 心跳、姿态、位置、模式、σ/μ、电池、告警 | 1–10+ Hz | “看不见”；飞机仍按最后模式飞 |
| 航电 CAN | 电调状态、外设 | 高 | 动力反馈丢失→保护策略 |

**测控联调冒烟（链 C）最小集**

1. 心跳稳定、延迟可接受  
2. 读姿态与模式  
3. 改一个无害参数并回读一致  
4. 模式切换命令有效且有原因码  
5. 断数传：行为符合“仅遥测丢失”还是与 RC 绑定策略（按配置）  
6. 断 RC：进入既定保护（返航/降落）

## 7 四条联调链：怎么打通（重点）

与《软件仿真重点》一致，这里给出 **可执行顺序与出口判据**。

### 7.1 总顺序（推荐）

```
D 仿真链（软件自洽）
  → C 测控链（能看见、能下指令）
    → B 传感链（估计可信、能解锁）
      → A 航电作动链（方向与行程正确）
        → 再回到 D/HIL 做故障注入
          → F 上机/缩比（有限科目）
```

不要一上来就全机通电转桨。

### 7.2 链 D — 仿真

| 步骤 | 动作 | 出口 |
|------|------|------|
| D1 | 纯软件在环：悬停 30–60 s | 姿态不发散 |
| D2 | 定点/定高 | 位置高度收敛 |
| D3 | 正常转换 | σ/μ 单调合理，高度波动可记录 |
| D4 | ABORT 注入 | 必回垂直语义 |
| D5 | 半物理：真飞控跑同一逻辑 | 环频率与输出与 ICD 一致 |

### 7.3 链 C — 测控

见 §6 冒烟；出口：双人检查表签字（操作+观察）。

### 7.4 链 B — 传感

| 步骤 | 动作 | 出口 |
|------|------|------|
| B1 | IMU 静态、六面/温漂按手册 | 解锁检查通过相关项 |
| B2 | 罗盘/GPS 室外 | 航向与位置合理 |
| B3 | 空速零点与动态 | 转换门槛可用 |
| B4 | 故意遮挡 GPS / 拔空速 | 保护动作符合 SRS |

### 7.5 链 A — 航电作动

| 步骤 | 动作 | 出口 |
|------|------|------|
| A1 | 卸桨或固定台；上锁确认 | 无意外起转 |
| A2 | 按通道表点动各电机（极低油门） | 转向与编号一致 |
| A3 | 倾转全行程慢速 | 端点=垂直/水平；限速有效 |
| A4 | 固定翼舵面打杆 | 方向符合机体轴定义 |
| A5 | （若 CAN）节点在线列表 | 无掉线；故障字可注入 |

### 7.6 关联系统“一次成功”的定义

同时满足：

- 测控可见 σ、μ、模式、阶段；  
- 作动方向与 ICD 一致；  
- 仿真或台架上 ABORT 可重复触发；  
- 断 RC 保护可重复；  
- 日志能回放上述过程。

## 8 与日志、参数的关系（运行可观测）

### 8.1 建议必录字段（运行级）

| 类 | 字段 |
|----|------|
| 时间与模式 | 时间戳、模式、切换原因、解锁 |
| 估计 | 姿态、角速度、位置、速度、空速、健康 |
| 控制 | 期望姿态、μ、σ、阶段、电机/舵面指令 |
| 保护 | 触发源、动作 |
| 链路 | RC 质量、数传状态 |

没有这些，联调“看起来不对”无法归零——属于系统运行设计的一部分，不是试飞事后才加。

### 8.2 参数分组与运行

改参不重编译；关键安全参数（转换门槛、ABORT 阈值、失控动作）变更需双人确认。参数包版本号进日志抬头。
