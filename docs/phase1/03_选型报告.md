## 1 选型原则与约束

| 维度 | 约束（来自协议/SRS） |
|------|----------------------|
| 算力 | 主 CPU ≥480 MHz；从 CPU ≥24 MHz |
| 传感 | MEMS 惯导集成；动静压；推荐三余度 IMU |
| 接口 | ≥2 路隔离 CAN；≥5 UART；≥16 PWM 或等效 |
| 存储 | 日志 ≥8GB |
| 环境 | **工作温度 -40℃ ~ +60℃** |
| 重量 | 飞控计算机 ≤2kg |
| 工程 | 驱动成熟、工具链可维护、供货周期可控、可二次开发 |

## 2 飞控计算机选型

### 2.1 候选方案

| 指标 | 方案 A：工业级 H7 旗舰板（推荐主选） | 方案 B：高集成双处理器板 | 方案 C：国产 H7 航电级（备选调研） | 协议要求 |
|------|--------------------------------------|---------------------------|--------------------------------------|----------|
| 主 CPU | STM32H7 系列 @480 MHz 级 | STM32H7 双核/单核 @480 MHz 级 | H7 国产化型号（待确认主频） | ≥480 MHz |
| 从 CPU | F1/F3 协处理 IO，≥72 MHz | 片内/外协 IO | 视板型 | ≥24 MHz |
| IMU | 典型三套 MEMS（如 ICM/BMI 组合） | 三余度 MEMS | 视配置 | MEMS 集成 |
| 气压 | 双气压常见 | 双气压 | 视配置 | 静压 |
| CAN | 双路隔离 CAN 常见 | 双 CAN | 视配置 | ≥2 隔离 CAN |
| UART | ≥6 | ≥5 | 视配置 | ≥5 |
| PWM | ≥16 | ≥16 | 视配置 | ≥16 或 DI/DO |
| 日志 | microSD，≥32GB 工业卡可配 | 同左 | 同左 | ≥8GB |
| **温度** | **须选工业/宽温版本或加温控** | 同左 | 以厂家宽温认证为准 | **-40~+60** |
| 重量 | 飞控板+外壳+线束 ≪2kg | 同左 | 同左 | ≤2kg |
| 生态 | 驱动/工具链成熟 | 成熟 | 需评估驱动工作量 | — |
| 风险 | 宽温版交期 | 宽温版交期 | 认证与驱动周期 | — |

> 说明：方案 A/B 对应业界成熟的 Cube 系 / Pixhawk 6X 级硬件形态；对外文档使用“工业级 H7 旗舰板 / 高集成双处理器板”表述，具体型号在采购合同与 ICD 中固化，并由甲方确认。

### 2.2 推荐结论

| 项 | 结论 |
|----|------|
| **主选** | 方案 A 工业级宽温版本（或同等 H7 三余度 IMU 板） |
| **并行备选** | 方案 B；若宽温版 A 交期 >4 周，立即切换 B 的宽温/温控方案 |
| **国产化** | 方案 C 作为四期或下一阶段导入，不挡本期首飞 |

**理由**：算力、IMU 余度、接口数量满足 SRS；工程风险最低；与半实物仿真、地面站工具链匹配。

### 2.3 宽温（-40℃）专项

| 策略 | 内容 | 适用 |
|------|------|------|
| 策略 1（优选） | 采购厂家工业级/宽温认证整板 | 交期允许 |
| 策略 2 | 标准温区板 + 机载温控舱（加热/隔热），飞控工作点维持在认证温度内 | 宽温板延期 |
| 策略 3 | 低温地面验证 + 飞行包线限制（过渡措施，需甲方书面同意） | 仅应急 |

**一期行动**：W1 向 ≥2 家供应商询价宽温版与交期；W2 锁定 PO。

### 2.4 电源与配电

- 机载低压输入经滤波与低压适配模块（交付清单含“低压适配模块及线缆”）  
- 飞控电源与舵机/电调动力电隔离或分区，防止大电流回灌  
- 建议双路电源输入或板载电容保持，满足短时掉电不死机（详细电气见 ICD）

## 3 关键航电选型

### 3.1 GNSS / RTK

| 项 | 推荐 |
|----|------|
| 接收 | 多星多频，支持 RTK；双天线航向可选（偏航增强） |
| 天线 | 航空级 GNSS 天线 1 块（交付清单）+ 地面差分天线按试飞场配置 |
| 接口 | UART / CAN（与 ICD UART 规划一致） |
| 余度 | 建议双 GNSS 实例，满足 REQ-F-SF-03 |

### 3.2 空速

| 项 | 推荐 |
|----|------|
| 探头 | 皮托空速管（交付清单） |
| 传感 | 数字差压，CAN 或 I2C/UART；尽量双空速或健康监控 |
| 用途 | 转换进入判据、失速保护、TECS |

### 3.3 数据链（主备）

| 项 | 推荐 |
|----|------|
| 机载 | 主备数据链机载端 1 套（协议交付） |
| 地面 | 地面天线 4 根（交付清单） |
| 要求 | 与地面站协议兼容；支持失效切换策略（REQ-F-RC-03） |

### 3.4 遥控器

| 项 | 推荐 |
|----|------|
| 形态 | 工业级多通道遥控器 1 台（交付） |
| 接收 | 双接收或热备份（推荐） |
| 失控 | 硬件失控位 + 飞控 RC failsafe 双重 |

### 3.5 Remote ID（合规关键路径）

| 能力 | 方案 | 说明 |
|------|------|------|
| 广播式 | 外置 BLE/WiFi Remote ID 模块 | 满足广播识别 |
| 网络式 | 4G/5G 模组 → UOM | 满足网络报送 |
| 实名/激活 | 与模块厂商 SDK 或自研适配层 | REQ-F-ID-01 |
| 失效处置 | 接入故障保护（REQ-F-ID-04） | 与 SF 模块联动 |

**推荐路径**：优先成熟第三方合规模块（缩短 2–3 人月风险），飞控侧做协议适配与失效策略；W1 询价，W3 方案评审，W8 硬件联调，W12 报送联调。

### 3.6 存储

工业级 microSD ≥32GB（满足 ≥8GB 并留余量），定期拷机验证写入可靠性。

## 4 半实物仿真系统

| 项 | 推荐 |
|----|------|
| 组成 | 实时仿真机或高性能工作站 + 接口箱 + 专用线缆 |
| 连接 | 与飞控 UART/CAN/HIL 通道按 ICD §6 |
| 能力 | 全模态闭环、故障注入、拷机 ≥1h |
| 交付 | 半实物仿真系统 1 套（二期） |

可选路径：真飞控板运行仿真传感器栈（Sim-on-Hardware 类）用于早期接口与时序验证；高保真气动仍建议外部模型联合仿真。
