## 1 引言

### 1.1 目的与范围

规定机载飞控软件的逻辑分层、模块职责、调度模型、关键状态机、数据流与二次开发接口，作为系统设计与实现约束。地面站架构仅作边界说明。

**分工**：本册（SDD-001）侧重结构与职责；**系统如何按节拍跑起来、一拍数据流、四条联调链的操作级说明**见配套分册 [11_系统运行与联调说明](11_系统运行与联调说明.md)（SDD-002）。两册一并作为“软件与仿真/联调”对甲材料。

### 1.2 设计原则

1. **分层解耦**：HAL → 驱动 → 估计 → 控制 → 模态；替换一层不波及无关层  
2. **估计与控制分离**：控制律只消费估计器输出，不直接读原始传感器  
3. **调度表驱动**：单进程主循环 + 固定频率任务表 + 时间预算 + 看门狗  
4. **模态化**：每模式独立进入/运行/退出；切换原因可记录  
5. **过渡专用状态机**：正向三阶段 + 主动中断回退  
6. **作动器抽象**：归一化力矩/舵面指令 → 通道映射 → PWM/CAN 等  
7. **参数化与全量日志**  
8. **纵深防御**：传感器余度、分层 failsafe、安全输出默认值  
9. **二次开发安全边界**：注入接口不得绕过解锁与保护  

### 1.3 关键权衡

| 议题 | 决策 | 理由 |
|------|------|------|
| 多进程消息总线 vs 单主循环 | **单主循环** | 确定性时序、任务边界原子、便于试飞归零 |
| 300kg 控制带宽 | 姿态环 ≥100Hz 可配置，默认按平台能力运行 | 大惯性物理带宽低，避免空转占用 |
| 板级余度 | 一期框架，分期实现 | 合同范围待确认（SRS OQ-04） |

## 2 总体架构

### 2.1 逻辑分层

```
┌──────────────────────────────────────────────────────────┐
│ 飞行模态层   增稳/定高/定点/自动/起降/返航/转换相关模式     │
├──────────────────────────────────────────────────────────┤
│ 控制律层     旋翼串级 · 固定翼L1/TECS · 过渡混合 · 倾转补偿 │
├──────────────────────────────────────────────────────────┤
│ 状态估计层   多通道EKF · 传感器一致性 · 风估计             │
├──────────────────────────────────────────────────────────┤
│ 驱动层       IMU/磁/气压/GPS/空速/电流/遥控/CAN外设        │
├──────────────────────────────────────────────────────────┤
│ HAL/BSP      时钟·总线·PWM·SD·Flash·看门狗·板级引脚        │
└──────────────────────────────────────────────────────────┘
        ║ 横向贯穿
        ╠═ 调度器（任务表/预算/看门狗）
        ╠═ 参数系统
        ╠═ 日志系统
        ╠═ 遥测通信（地面站协议）
        ╚═ 故障保护管理器
```

### 2.2 物理部署

| 节点 | 运行内容 |
|------|----------|
| 飞控计算机（主 MCU） | 本 SDD 描述的全部机载软件 |
| IO 协处理（从 CPU） | PWM/IO 刷新、部分安全输出（板型相关） |
| 地面站 PC | 任务、参数、曲线、日志 |
| 仿真机（SITL/HIL） | 动力学与传感器模型；HIL 时飞控为真件 |

### 2.3 进程与任务模型

- **单进程、单主循环**：循环节拍由惯性采样就绪驱动，保证估计-控制同拍对齐。  
- **任务表**：每项任务声明目标频率、最坏执行预算、优先级。  
- **分频**：低频任务由主循环 tick 整数分频触发，非独立线程时钟。  
- **禁止**：控制关键路径上的动态内存抖动、无界锁等待、阻塞式网络调用。

### 2.4 主循环与一拍数据流（摘要）

上电后：HAL → 驱动自检 → 加载参数 → 估计初始化 → 挂接任务表 → 主循环。主循环每拍：

1. 等待惯性新采样 → tick  
2. 按分频执行到期任务（估计、模式、控制、输出、通信、保护、日志等）  
3. **同一拍内逻辑顺序（飞行中）**：驱动采样 → 状态估计 → 遥控/GCS 指令合并 → 故障保护扫描 → 当前模式算出期望 → 旋翼和/或固定翼控制 →（转换则按 μ 混合并更新倾转 σ）→ 混控/通道映射 → PWM/CAN 输出  

转换中旋翼与固定翼控制可并行计算，输出按混合权重 μ 合成；倾转进度 σ 单独限速。中断回退（ABORT）在保护条件满足时于状态机内完成回垂直与模式切换。

频率表、模式对照、联调出口判据的展开见 **SDD-002 §1–§7**。

## 4 调度与实时设计

### 4.1 典型任务频率（可配置，表为设计目标）

| 任务类别 | 目标频率 | 说明 |
|----------|----------|------|
| 惯性等待与主循环 | 100–400 Hz | 由板型与 SCHED 类参数决定 |
| 姿态/角速率控制 | 与主循环同量级 | 旋翼内环 |
| 位置/高度控制 | 50–100 Hz | 旋翼外环 |
| 固定翼姿态/导引 | 50 Hz 量级 | L1/TECS |
| GPS 更新 | 5–10 Hz | |
| 日志写入 | 高带宽分片 | 不阻塞控制 |
| 遥测 | 按链路带宽 | |
| 故障保护扫描 | ≥10 Hz | |

### 4.2 时间预算与看门狗

- 每任务声明预算微秒；超预算记日志并计入健康度。  
- 主循环看门狗：超时复位或切安全输出（板型策略）。  
- 解锁前检查调度频率下限（满足 REQ-P-RT-01）。

### 4.3 中断与 DMA

仅用于驱动层采集与底层 IO；控制律在主循环上下文运行，避免在 ISR 中做浮点重计算。

## 5 关键状态机

### 5.1 飞行模式（逻辑集合）

| 模式组 | 示例模式 | 说明 |
|--------|----------|------|
| 旋翼 | 增稳、定高、定点、旋翼降落、旋翼返航 | VTOL 推力主导 |
| 固定翼 | 姿态增稳、巡航、盘旋、自动航线（FW 段） | 气动舵面主导 |
| 自动 | 统一 AUTO，内部按航段类型分派 VTOL/FW 控制 | |
| 保护 | 故障触发的返航/降落/迫降 | 高优先级切入 |

切换记录：目标模式、原因码（遥控、GCS、failsafe、转换失败等）、时间戳。

### 5.2 转换状态机（满足 REQ-F-TR）

```
          切入前飞/满足进入条件
   IDLE ─────────────────────► AIRSPEED_WAIT
                                  │ 空速达标
                                  ▼
                              TRANS_TIMER ──── 权重0→1，倾转推进
                                  │ 完成判据
                                  ▼
                               TRANS_DONE ─── 固定翼接管

任意阶段：中断条件 ──► ABORT ──► 倾转回垂直 + 旋翼保护模式
任意阶段：超时 ──────► 按配置 ABORT 或强制完成（可配置，默认偏安全回退）
```

**ABORT 触发（设计基线）**：空速持续低于门槛、姿态超限、高度掉落率超限、动力/电机异常、遥控强制中断、估计器严重降级。

### 5.3 解锁状态机

锁定 →（检查通过）→ 解锁 →（上锁指令/保护）→ 锁定。  
检查项：传感器健康、校准、电量、模式允许、围栏、合规模块状态（分期）、遥控有效等。

### 5.4 故障保护分级

| 级别 | 含义 | 典型动作 |
|------|------|----------|
| L1 告警 | 可继续飞 | GCS 告警、日志 |
| L2 降级 | 能力下降 | 限制模式、传感器切换 |
| L3 返航 | 任务中止 | RTL |
| L4 降落/迫降 | 立即安全 | 旋翼降落或固定翼迫降场 |

## 6 数据流与控制流

### 6.1 旋翼

```
遥控/导航 → 期望姿态/爬升率
    → 角度控制 → 角速率 PID → 归一化力矩
    → 混控矩阵 → [倾转补偿] → 电机通道
高度：位置Z → 速度Z → 加速度/油门
```

联调关注：拨杆后力矩符号、电机差动方向、高度环趋势（SDD-002 §2.1 / 链 A）。

### 6.2 固定翼

```
L1 → 期望滚转；TECS → 期望俯仰与油门
    → 舵面 PID（含空速缩放）→ 副翼/升降/方向
```

联调关注：航线侧偏、舵面中立与方向、空速缩放是否在低速变软（SDD-002 §2.2）。

### 6.3 转换

```
μ∈[0,1]：旋翼输出×(1-μ) ‖ 固定翼输出×μ
σ∈[0,1]：倾转限速；推力倾转补偿（见控制律）
阶段：空速等待 → 计时混合 → 完成；任意异常 → ABORT
```

联调关注：遥测可见 μ/σ/阶段；台架可重复触发 ABORT（SDD-002 §2.3、§4、§7）。

### 6.4 估计路径与时延预算

传感器采样 → 驱动缓冲 → 多通道估计更新 → 控制读取同一拍状态。  
端到端（采样到作动刷新）目标：落在主循环周期量级；板型测定后写入参数基线与 HIL 报告。

### 6.5 通信在闭环中的位置

控制闭环 **不依赖** 地面站每拍到达；测控提供指令事件与遥测观察。遥控丢失走故障保护；数传丢失按配置与 RC 策略区分。航电 CAN/PWM 属于作动与反馈，见 ICD 与 SDD-002 §5–§6。

## 7 余度与健康管理

### 7.1 传感器级（一期实现范围）

- 多 IMU：一致性检查 + 估计多通道（lane）评分切换  
- GPS/空速：多实例切换与丢失保护（REQ-F-SF-03/05）  
- 健康度：写入日志与遥测  

### 7.2 板级余度（扩展点）

- 心跳、关键状态快照、接管仲裁、输出静默策略  
- 与 SRS OQ-04 绑定；未纳入本期则仅保留接口与文档  

### 7.3 动力通道健康

- 电流/转速/电调状态（若可用）→ 单通道失效检测（REQ-F-SF-07）  
- 失效后剩余分配或切保护模式（控制律 §7）

## 11 关联系统联调在架构中的位置

软件交付合格 ≠ 系统可飞。架构上要求实现期按四条链验收（细节在 SDD-002）：

| 链 | 两端 | 架构落点 |
|----|------|----------|
| D 仿真 | 软件 ↔ 模型/HIL | 调度与控制可在仿真后端复用同一任务表语义 |
| C 测控 | 软件 ↔ 数传/RC/GCS | 通信模块；保护模块 |
| B 传感 | 软件 ↔ IMU/GPS/空速 | 驱动 + 估计健康 |
| A 航电 | 软件 ↔ 电调/舵机/倾转 | 混控 + 通道映射 + HAL 输出 |

推荐打通顺序：D → C → B → A → HIL 故障注入 → 上机。出口判据见 SDD-002 §7.6。
