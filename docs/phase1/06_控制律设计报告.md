## 1 引言

### 1.1 设计目标

满足 SRS 功能需求 REQ-F-MC/TR/FW 与性能 REQ-P-*；在 300kg 级大惯性条件下实现平滑、可中断、可复现的全模态控制。

### 1.2 设计原则

- 串级控制，带宽内环高于外环  
- 前馈 + 反馈；积分抗饱和  
- 平滑限幅与速率限制  
- 转换段双控制器并行按权重混合，禁止硬切换  
- 安全优先：ABORT 默认使能  

### 1.3 符号

| 符号 | 含义 |
|------|------|
| φ,θ,ψ | 滚转、俯仰、偏航 |
| p,q,r | 机体角速度 |
| δ_a,δ_e,δ_r | 副翼、升降、方向 |
| T_i | 第 i 电机归一化推力 |
| σ | 倾转进度 0=垂直，1=水平 |
| μ | 转换混合权重 progress，0=纯旋翼，1=纯固定翼 |
| V_a | 空速 |

## 2 总体控制架构

```
                ┌──────── 任务/遥控/保护 ────────┐
                ▼                               ▼
        期望轨迹/姿态/模式                 强制模式/限幅
                │
        ┌───────┴────────┐
        │  模态仲裁       │← failsafe / ABORT
        └───────┬────────┘
     ┌──────────┼──────────┐
     ▼          ▼          ▼
  旋翼串级   过渡混合管理   固定翼 L1+TECS
     │          │          │
     └────► 权重 μ ◄───────┘
                │
        倾转 σ + 补偿
                │
           混控/舵面映射 → 作动器
```

估计器提供姿态、位置、速度、空速、风；控制律不直接使用未融合原始 IMU（除速率环用最新陀螺）。

## 3 旋翼模态控制律

### 3.1 角速率环

对 p,q,r 分别 PID（含滤波）：

\[
u_{p,q,r} = K_p e + K_i\int e + K_d \dot{e} + FF
\]

输出为归一化力矩指令，限幅防饱和；积分在限幅时冻结或回退。

### 3.2 角度环

期望欧拉角 → 姿态误差（四元数或欧拉，实现选四元数避免奇异）→ 期望角速度 → 速率环。  
输入整形限制期望角加速度，改善大飞机超调。

### 3.3 水平位置 / 速度环

定点/自动：位置误差 → 期望速度 → 速度 PID → 期望倾斜角（限幅）→ 角度环。  
增稳：杆量直接映射期望角，跳过位置环。

### 3.4 高度环

期望高度/爬升率 → 垂直速度 → 垂直加速度/总推力指令。  
起飞、降落有专用爬升率剖面与触地检测逻辑。

### 3.5 混控

\[
T_i = T_{thr} + u_{roll} r_i + u_{pitch} p_i + u_{yaw} y_i
\]

归一化后若 max T_i > 1 则等比缩放，优先保证姿态（实现上可配置优先级）。

### 3.6 模式差异

| 模式 | 位置环 | 高度环 | 角度来源 |
|------|--------|--------|----------|
| 增稳 | 关 | 手动油门或简易 | 杆量 |
| 定高 | 关 | 开 | 杆量 |
| 定点 | 开 | 开 | 位置环 |
| 自动 VTOL 段 | 开 | 开 | 任务 |

### 3.7 旋翼参数表（逻辑名）

| 参数 | 含义 | 默认起点 | 范围提示 |
|------|------|----------|----------|
| MC_ROLL_P/I/D | 滚转速率 PID | 仿真实标定 | — |
| MC_PITCH_* | 俯仰速率 | | |
| MC_YAW_* | 偏航速率 | 偏保守 | |
| MC_ANG_ROLL_P | 角度 P | | |

## 4 固定翼模态控制律

### 4.1 横向

- **L1 导引**：侧向误差 → 期望横向加速度 →  
  \[
  \phi_{cmd} = \arctan(a_{lat}/g)
  \]  
  限幅 φ_max。  
- **滚转姿态 PID**：φ 误差 → 副翼 δ_a，带空速缩放。

### 4.2 纵向（TECS）

总能量与能量分配误差 → 俯仰指令与油门指令解耦：  
- 油门主要修正能量不足/过剩  
- 俯仰主要修正势能/动能分配  
限幅：θ_min/max、油门上下限、下沉率。

### 4.3 偏航

协调转弯：期望 r ≈ g tanφ / V_a；方向舵阻尼侧滑（若有侧滑估计/加速度计代理）。

### 4.4 空速缩放

舵面效力 ∝ 动压，PID 输出乘 speed_scaler，防止高速过硬、低速过软。

### 4.5 固定翼参数表（逻辑名）

| 参数 | 含义 |
|------|------|
| FW_L1_PERIOD / DAMPING | L1 |
| FW_TECS_* | 能量控制一组 |
| FW_RLL_P/I/D 等 | 姿态 |
| FW_ARSPD_MIN/MAX | 空速带 |
| FW_ROLL_LIM | 最大滚转 |

## 5 转换模态控制律（核心）

转换是本机型最高技术风险，也是协议硬缺口（REQ-F-TR-05 中断回退）。本章按“状态机 → 每阶段行为 → 权重混合 → 倾转补偿 → 油门融合 → 中断 → 可观测与验证”展开，可直接用于台架与仿真验收。

### 5.1 设计约束（来自特性分析）

1. 机翼接住重量之前，旋翼垂直分量不得掉光——即升力移交必须连续。  
2. 300kg 惯性大：倾转速率与混合速度取慢不取快，避免阶跃。  
3. 反扭矩偏航随倾转失效，必须由差动前向推力接力，不能留偏航真空带。  
4. 任何时刻允许人工或自动 ABORT，且 ABORT 不依赖单一判据。  

### 5.2 状态机与迁移

```
   旋翼模式，收到转前飞请求
IDLE ───────────────────────► AIRSPEED_WAIT
                                 │  V_a ≥ TR_ASPD_MIN 持续 TR_ASPD_HOLDT
                                 ▼
                              TRANS_TIMER  (μ 0→1，σ 继续推进)
                                 │  完成判据（见 5.6）
                                 ▼
                              TRANS_DONE   (μ=1，固定翼接管)

任意阶段 ──► ABORT（见 5.7）──► 倾转回垂直 + μ→0 + 保护模式
任意阶段 ──► 总超时 TR_FAIL_TMO ──► 按配置：默认 ABORT
```

反向（固定翼→旋翼）：切旋翼模式即进入回退路径，倾转以 TR_TILT_RATE_DN 回零，μ→0，旋翼高度环接管，不需要空速门槛。

### 5.3 各阶段行为（逐拍）

| 阶段 | 旋翼控制器 | 固定翼控制器 | 倾转 σ | 高度/油门 |
|------|------------|--------------|--------|-----------|
| AIRSPEED_WAIT | 全量运行，维持姿态与高度 | 计算但舵面 μ≈0 不输出 | 按前飞需求小角度推进，加速 | 旋翼高度环主导 |
| TRANS_TIMER | 输出 ×(1−μ) | 舵面 ×μ | 继续推进至前飞位 | 见 §5.5 油门融合 |
| TRANS_DONE | 按构型关闭或仅前飞推力 | 全量 | 前飞位锁定 | TECS 油门 |
| ABORT | 全量恢复，高度环立即接管 | 舵面回 μ≈0 | 以 DN 速率回垂直 | 旋翼油门恢复，清前飞饱和 |

关键点：**两套控制器在 TIMER 段并行计算**，不是先关一个再开另一个；靠 μ 平滑移交控制权。这与运行说明 SDD-002 §2.3 一致。

### 5.4 权重混合 μ

线性基线：

\[
\mu(t)=\mathrm{sat}\big((t-t_1)/T_{trans},\,0,\,1\big)
\]

300kg 推荐 **S 曲线**（两端缓、中段匀），降低阶段切换处的姿态突变：

\[
\tau=\frac{t-t_1}{T_{trans}},\qquad
\mu=\tfrac12-\tfrac12\cos(\pi\tau)
\]

| 量 | 乘子 |
|----|------|
| 旋翼力矩/油门 | 1−μ |
| 固定翼舵面 | μ |
| 固定翼前飞油门 | 见 §5.5 按 σ 融合 |

S 曲线与线性可由参数 TR_WEIGHT_CURVE 切换，首飞用 S 曲线。

### 5.5 油门融合（全倾转构型）

全倾转构型没有独立前飞螺旋桨，同一批电机既要提供升力又要提供推力。TIMER 段不是简单地把两个油门相加，而是按倾转角融合：

\[
r=\frac{\sigma-\sigma_{asp}}{1-\sigma_{asp}},\qquad
T_{cmd}=T_{mc}(1-r)+T_{fw}\,r
\]

- \(T_{mc}\)：旋翼高度环算出的油门（维持升力）  
- \(T_{fw}\)：TECS 算出的前飞油门  
- \(\sigma_{asp}\)：空速刚达标时的倾转角（融合起点）  

物理含义：

| 时刻 | σ | r | 油门来源 |
|------|---|---|----------|
| 空速刚达标 | σ_asp | 0 | 100% 旋翼 |
| 过渡中段 | ≈0.5 | 0.5 | 各一半 |
| 完成 | ≈1 | 1 | 100% 固定翼 |

非全倾转构型（有独立前飞电机）则旋翼油门按 1−μ 衰减、前飞电机按 μ 建立，无需此融合。

### 5.6 进入、完成、超时判据

**进入 AIRSPEED_WAIT 前置条件（全部满足才允许转前飞）**

- 当前在旋翼模式且高度 > TR_ENTRY_ALT  
- 电量、链路、估计器健康  
- 空速计有效（若依赖空速门槛）  
- 无未处理的 failsafe  

**进入 TRANS_TIMER**

\[
V_a \ge TR\_ASPD\_MIN \;\text{持续}\; TR\_ASPD\_HOLDT
\]

（用持续时间去抖，避免空速抖动反复横跳。）

**完成 TRANS_DONE（建议全部满足）**

- σ ≥ 前飞位阈值  
- V_a ≥ TR_ASPD_MIN 保持  
- |φ|、|θ| 在允许带内  
- μ 已到 1（时间走完或 σ 到限）  

**超时**

从进入转换起计时超过 TR_FAIL_TMO：默认切 ABORT；若配置为“强制完成”，必须同时满足空速与姿态安全条件，否则仍回退。

### 5.7 主动中断回退（ABORT）— REQ-F-TR-05/06

**触发（逻辑或；阈值带迟滞与持续时间防抖）**

| 触发源 | 条件 | 参数 |
|--------|------|------|
| 空速不足 | V_a < TR_ASPD_MIN 持续 > TR_ABORT_ASPD_T | TR_ABORT_ASPD_T |
| 姿态超限 | \|φ\| 或 \|θ\| > TR_ABORT_ATT 持续 > TR_ABORT_ATT_T | TR_ABORT_ATT(_T) |
| 高度掉落 | 下沉率 > TR_ABORT_DZDT 或高度损失 > TR_ABORT_DALT | TR_ABORT_DZDT/DALT |
| 动力异常 | 单电机/电调故障标志 | （见 §7.3） |
| 估计故障 | EKF 严重降级/姿态不可信 | SF_* |
| 人工 | 遥控“中断转换”开关或 GCS 指令 | — |
| 超时 | t > TR_FAIL_TMO 且未配置强制完成 | TR_FAIL_TMO |

**动作序列（拍内）**

1. 置阶段 = ABORT，记录事件（时间、触发源、当前 V_a/σ/μ/姿态）  
2. 倾转目标 σ* = 0，以 TR_TILT_RATE_DN 限速回垂直  
3. μ → 0，旋翼姿态/高度环全量恢复  
4. 清除前飞 TECS 油门饱和，高度环接管总推力  
5. 按 TR_ABORT_ACT 切入：旋翼降落 / 定点悬停 / 旋翼返航（首飞建议旋翼降落或悬停）  

**不允许**的行为：ABORT 后又自动重新发起转前飞（需人工再次指令）。

### 5.8 倾转补偿（物理推导）

电机倾转 σ 后，推力方向偏转，导致三个问题，逐一补偿。

#### 5.8.1 升力损失：1/cos 放大

电机垂直时推力全为升力；倾转 θ=σ·90° 后垂直分量 ∝ cosθ。若不补偿，同样油门在过渡中升力打折、飞机掉高。

\[
T_i \leftarrow T_i\cdot\frac{1}{\cos(\sigma\cdot\pi/2)+\varepsilon}
\]

数值示例（倾转 45°，需 0.5 升力）：补偿前垂直升力 0.5·cos45°=0.35；补偿后推力 0.5/cos45°≈0.71，垂直分量回到 0.5，同时水平分量 0.5 提供前飞加速。

对**所有通道**（油门 + 滚转 + 俯仰 + 偏航差动）统一放大，因为它们的效力都按 cosθ 同比例衰减。

#### 5.8.2 滚转差动效力衰减

倾转后左右电机差动产生的是水平推力差，对滚转的力矩臂失效（力方向变水平，力臂在 Y 轴）。补偿方式：随 σ 增大，把倾转电机的差动分量向平均推力平滑靠拢：

\[
T_i \leftarrow \sigma\cdot\bar T + T_i(1-\sigma)
\]

即倾转越多，差动越小，避免无效的大推力差。

#### 5.8.3 偏航：反扭矩衰减、差动前向推力接力

| 倾转角 | 反扭矩偏航 | 差动前向推力偏航 | 总能力 |
|--------|-----------|------------------|--------|
| 0° | 100% | 0% | 正常 |
| 45° | 71% | 71% | 充足 |
| 90° | 0% | 100% | 正常 |

差动前向推力偏航叠加项（概念）：

\[
\Delta T_i \propto r_i\cdot(u_{yaw}+u_{yaw,ff})\cdot\sin(\sigma\cdot\pi/2)\cdot k_{yaw}
\]

其中 \(r_i\) 为电机左右位置系数（左/右符号相反），决定哪侧加速。用乘法 sin 而非除法，是为了在小角度时不出现数学奇点（除法在 0° 发散）。

#### 5.8.4 补偿后归一化

补偿后若任一电机 >1，按比例整体缩放（记录饱和标志）。饱和意味着该拍控制力不足，是 ABORT 高度/姿态判据要兜的底。

### 5.9 倾转速率限制

\[
\sigma_{k+1}=\sigma_k+\mathrm{sat}\big(\sigma^*-\sigma_k,\ \pm\dot\sigma_{max}\Delta t\big)
\]

前倾用 TR_TILT_RATE_UP，回垂直用 TR_TILT_RATE_DN（回退可略快，但仍受机构能力限制）。σ 与 μ 解耦：σ 是机构物理角度，μ 是控制权重，二者各自限速。

### 5.10 可选：尾翼倾转电机分段功率限制

若构型含尾翼倾转电机，前旋翼下洗流会在过渡中段冲击尾翼。提供基于 σ 的功率曲线（S 形中段降功率），并可叠加空速因子：

\[
P_{lim}(\sigma,V_a)=P_{base}(\sigma)\cdot(1-k_v\,V_a/V_{max})
\]

首飞若尾电机影响不显著可关闭（TR_TAIL_PWR_LIM=1）。仅在试飞日志显示尾段过载/俯仰扰动时启用。

### 5.13 与性能指标关系

| 指标 | 设计手段 | 验证 |
|------|----------|------|
| 姿态波动 <5° | S 曲线 μ、倾转限速、保守 PID、姿态 ABORT | SIM-TR-01 |
| 高度波动 <10 m | 1/cos 补偿、高度环保持、下沉率 ABORT | SIM-TR-01/02 |
| 中断可回退 | ABORT 多判据 + 回垂直 + 旋翼接管 | SIM-TR-02/03/04 |

## 6 导航与任务

- 航点切换与 VTOL/FW 航段类型决定调用旋翼或固定翼外环  
- 自动起飞：垂直爬升至安全高 → 可选转换 → 航线  
- 自动降落：反向转换（若需要）→ 垂直降落  
- 返航：按当前构型选择旋翼 RTL 或 FW 回场再转换降落（策略可配）

## 7 安全控制律

### 7.1 保护分级总表

| 保护 | 触发（概念） | 控制动作 | 对应仿真 |
|------|--------------|----------|----------|
| 低电量 | 电压/容量分级阈值 | L1 告警 → 限半径 → L3 返航 → L4 降落 | SIM-FI-BAT |
| GNSS 丢失/降级 | 定位质量下降/星数不足 | 切姿态类模式或安全降落；禁止位置模式 | SIM-FI-GPS |
| RC 丢失 | 信号丢失超时 | 按配置 RTL/降落 | SIM-FI-RC |
| 围栏 | 越界 | 回弹或 RTL | SIM-FI-FENCE |
| 高度异常 | 超出高度带或下沉率超限 | 限爬升、切旋翼保护、必要时迫降 | SIM-FI-ALT |
| 失速 | V_a < 失速阈值且非旋翼状态 | 低头增速、增油门；必要时转旋翼构型 | SIM-FI-ASPD |
| 姿态异常 | 大姿态/角速度超极限 | 切增稳/旋翼；地面则停转保护 | SIM-FI-IMU |
| **单电机失效** | 见 §7.3 | 转换中立即 ABORT；悬停中剩余分配或保护降落 | SIM-FI-MOT |
| 识别失效 | RID 模块掉线 | 告警/限制起飞（按合规策略） | SIM-FI-RID |

所有保护动作必须写日志：触发源、触发时刻、当时模式/姿态/高度/动作。

### 7.2 失速与高度异常保护（重点）

**失速保护逻辑（固定翼或转换中）**

1. 空速低于 FW_ARSPD_STALL 持续 T_stall  
2. 解除姿态/高度保持的上仰需求（低头优先增速）  
3. 油门推到保护值  
4. 若高度仍下降或空速继续掉，且构型允许：**转旋翼**（等效反向转换 + ABORT 路径）  
5. 旋翼模式下不触发失速保护（旋翼无空速依赖）  

阈值取实测 Vs 的安全系数（特性分析 CI-04），首飞偏保守。

**高度异常保护**

- 超过最大允许高度：限制爬升、告警  
- 非指令下沉率超 TR_ABORT_DZDT：若在转换中→ABORT；若在固定翼→增油门/低头；若在旋翼→高度环全权限接管  
- 近地异常下沉：触发自动降落逻辑（若高度计/地形数据可信）

### 7.3 单电机（动力通道）失效

**检测来源（任一即可，多源更可靠）**

- 电调反馈转速异常/掉帧（CAN 电调）  
- 电机电流与指令严重不符  
- 飞控指令非零而电机无反馈  
- 姿态控制持续要求单侧极限推力仍无法维持姿态  

**动作（按飞行阶段）**

| 阶段 | 动作 |
|------|------|
| 旋翼悬停 | 若剩余电机可维持姿态（偶数对称失效可重分配）：重算混控矩阵，立即保护降落；不可维持：进入自旋/迫降程序 |
| 转换中 | **立即 ABORT**（见 §5.7），不完成前飞转换；回旋翼翼图稳定后保护降落 |
| 固定翼 | 维持固定翼飞行（动力不对称用舵面补偿），就近迫降；不尝试转旋翼（除非推力足够） |

**禁止行为**：单电机失效后继续自动转换或继续航线。一期冻结“检测→ABORT/降落”策略；剩余推力重分配矩阵在二期仿真中验证后启用。仿真用例 SIM-FI-MOT 必须在二期通过。

### 7.4 与解锁/模式仲裁的关系

- failsafe 优先级高于飞行员/GCS 模式请求，但不高于地面停转硬开关  
- 保护切入的模式记录原因码（RC_FAILSAFE / BAT_LOW / MOTOR_FAIL / TRANS_ABORT 等）  
- 解锁检查（预 arm）包含：传感器健康、校准、参数包版本、围栏、（分期）RID 状态——检查不通过禁止解锁

### 7.5 保护参数（逻辑名）

| 参数 | 含义 |
|------|------|
| SF_BAT_LOW/CRT | 低电量/危急阈值 |
| SF_GPS_* | GNSS 保护阈值 |
| SF_RC_TIMEOUT | RC 超时 |
| SF_ALT_MAX / SF_DZDT | 高度带与下沉率 |
| FW_ARSPD_STALL | 失速空速 |
| SF_MOT_ENABLE | 单电机检测使能 |
| SF_FAIL_ACTION_* | 各保护默认动作 |

具体数值在仿真与试飞中整定，首飞前写入参数基线。

## 8 稳定性与性能（一期）

### 8.1 带宽分配（定性）

速率环 > 角度环 > 速度环 > 位置环；TECS 带宽低于短周期增稳。

### 8.2 抗饱和

积分限幅、退饱和、推力归一化优先级（姿态优先于高度的策略可配，转换段建议姿态优先）。

### 8.3 验证

全部定量结论以仿真计划用例与试飞日志为准；本期不宣称已达标，仅宣称结构可支撑达标。

## 9 参数整定策略

1. **SITL**：先悬停角速度/角度，再高度位置，再 FW 舵面，再转换。  
2. **HIL**：确认真实时序下无振荡。  
3. **缩比机**：小步过渡，每架次改一组参数。  
4. **300kg**：用特性分析建议起点，只放大惯性相关（倾转更慢、过渡更长），PID 再现场精调。  
5. 参数包命名：`ACFT300_PTyymmdd_vx.parm`，支持回滚。
