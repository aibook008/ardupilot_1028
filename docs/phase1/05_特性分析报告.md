## 2 构型与坐标系

### 2.1 构型假设（一期基线）

- 倾转类型：**连续倾转**（舵机可在 0°–90° 连续定位）  
- 动力：多台倾转旋翼电机 + 固定翼气动舵面（副翼/升降/方向）  
- 可能含尾部辅助动力或尾翼受下洗影响（若实机无尾倾转电机，则功率限制条款不适用）  

正式构型图、电机编号、力臂在总体 ICD/总体方案中固化后回填本节。

## 3 旋翼模态特性

### 3.1 悬停配平

- 总拉力 ≈ 重量；单电机拉力按布局分配。  
- 功率：按旋翼效率与盘载估算（⚠ 待桨叶数据）。  
- 配平姿态：无风时近水平；有常值风时需倾斜产生水平力。

### 3.2 操纵功效（定性）

| 通道 | 机制 | 大飞机注意 |
|------|------|------------|
| 滚转/俯仰 | 差动拉力 | 惯大 → 角加速度小 → PID 宜偏软、限幅防饱和 |
| 偏航 | 反扭矩差动 +（倾转时）水平差动 | 过渡段功效迁移，见 §5 |
| 高度 | 总推力 | 地面效应导致近地拉力增益变化 |

### 3.3 地面效应与下洗

- 近地悬停：地面效应使需用功率下降，离地瞬间可能下沉——起降高度环需足够刚度与油门裕度。  
- **前旋翼下洗冲击机翼/尾翼**：转换中俯仰力矩扰动 ⚠ 需 CFD 或试飞确认；控制上预留升降舵前馈/尾电机功率限制接口。

### 3.4 稳定边界建议（设计输入）

| 项 | 建议（占位） |
|----|----------------|
| 最大倾斜角（定点） | 20°–30°（可配） |
| 最大爬升率 | 按动力余量，试飞标定 |
| 近地高度保护 | 与 REQ-F-SF-04 联动 |

## 4 固定翼模态特性

### 4.1 巡航配平（占位）

| 项 | 说明 |
|----|------|
| 配平迎角/升降舵 | ⚠ 待升阻曲线 |
| 需用推力 | ⚠ 待阻力极曲线 |
| 巡航速度带 | 高于失速裕度；与转换完成空速衔接 |

### 4.2 静动稳定（定性要求）

- 纵向：静稳定或可控的弱不稳定 + 增稳；短周期阻尼由俯仰阻尼提供。  
- 横航向：垂尾/方向舵提供航向静稳定；副翼滚转；协调转弯由控制律实现。

### 4.3 失速与包线

| 项 | 设计输入 |
|----|----------|
| 失速指示空速 Vs | ⚠ TBD；保护阈值取 Vs×安全系数 |
| V-n / 高度-速度包线 | ⚠ 甲方总体；飞控做软件限幅 |
| 舵效随动压 | TECS/姿态环需空速缩放（控制律已规划） |

## 5 转换模态特性（重点）

### 5.1 升力移交

```
倾转角 θ: 0°(垂直) → 90°(水平)
旋翼垂直分量 ∝ cosθ → 逐渐减小
机翼升力 ∝ 动压 × CL → 随空速增加
目标：机翼接住重量之前，旋翼垂直分量不得掉光
```

### 5.2 配平轨迹（概念）

| 阶段 | 空速 | 倾转 | 控制主导 |
|------|------|------|----------|
| 进入 | 低 | 小角度推进 | 旋翼 |
| 加速 | 升至门槛以上 | 中等 | 混合 |
| 完成 | ≥ 最小前飞空速 | 近水平 | 固定翼 |

**推荐工程门槛（占位，试飞标定）**

| 参数 | 300kg 建议起点 | 说明 |
|------|----------------|------|
| 转换空速门槛 | ≥ 1.2×Vs（⚠ Vs 待定） | 进入 TRANS_TIMER 条件 |
| 倾转速率上 | 10–20 °/s | 小于轻小机默认，防突变 |
| 倾转速率下 | 15–25 °/s | 回悬停可略快 |
| 过渡时间 | 10–20 s | 大惯性加速 |
| 失败超时 | 20–30 s | 默认偏 ABORT |

### 5.3 危险区识别

| 危险区 | 机理 | 控制对策 |
|--------|------|----------|
| 功效谷底 | 反扭矩偏航减弱、气动舵面未达效 | 偏航差动推力补偿；限制 yaw 需求 |
| 高度掉落 | 1/cosθ 补偿不足或饱和 | 推力补偿 + ABORT 高度率判据 |
| 下洗俯仰 | 桨翼/尾翼干扰 | 限功率、升降前馈、减倾转速率 |
| 空速不足硬推倾转 | 机翼未接升力 | **禁止**；空速等待 + 中断回退 |
| 姿态发散 | 混合权重过快 | S 曲线 progress；姿态超限 ABORT |

### 5.4 进入 / 完成 / 中断判据建议

**进入（旋翼→固定翼）**

- 模式允许；高度 > 安全高；电量/链路健康；估计器正常  
- 飞行员或任务触发  

**完成**

- 倾转 ≥ 完成角；空速 ≥ 门槛并保持 N 拍；姿态在带内；progress→1  

**中断（ABORT）**

- 空速低于门槛持续 T1  
- |滚转|或|俯仰|超限持续 T2  
- 高度掉落率超限  
- 动力异常 / 单电机失效  
- 遥控“中断转换”开关  
- 估计严重降级  

### 5.5 对控制律的硬约束（输出给文档 06）

1. 必须实现主动 ABORT，不能仅靠超时。  
2. 倾转速率必须可配且对 300kg 默认偏慢。  
3. 推力补偿与饱和处理必须进仿真用例。  
4. 尾部动力若存在，转换中段功率限制可配。
