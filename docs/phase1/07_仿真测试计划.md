在真实试飞前，验证控制律、转换中断、混控补偿与故障保护逻辑；为缩比机/验证机试飞提供预整定参数与风险收敛证据。

## 3 模型要求

### 3.1 机体

- 六自由度刚体；倾转自由度 σ；可选地面效应  
- 质量/惯量/重心可配置拉偏  

### 3.2 动力与舵机

- 一阶/二阶延迟、饱和、速率限制  
- 失效模式：单机关推力、卡死、响应变慢  

### 3.3 传感器

- 噪声、偏置、丢包、卡死、延迟  
- 多 IMU/GPS 实例可独立故障  

### 3.4 环境

- 常值风、阵风、湍流等级  
- 转换段强制加风扰用例  

### 3.5 置信度

气动数据到位前：L1 以逻辑与趋势为准；**不得**仅凭 L1 宣称性能达标。数据到位后升 L2 再评估 REQ-P。

## 5 测试用例

### 5.0 用例格式与通用约定

每个用例按以下要素填写（表格行是索引，细节在用例描述段）：

| 要素 | 含义 |
|------|------|
| 前置 | 模式、高度、空速、参数包版本、模型版本 |
| 步骤 | 可复现操作序列 |
| 注入 | 故障/扰动的触发时机与数值 |
| 期望-行为 | 模式、阶段、作动方向 |
| 期望-性能 | 误差/波动阈值（对应 REQ-P） |
| 期望-日志 | 必须出现的事件名、μ/σ/阶段字段（对应控制律 §5.12） |
| 判废 | 出现即失败（失控、触地、ABORT 应动未动、错误重发转换） |

**通用通过准则**：不失控、不异常触地、日志完整、模式/阶段/事件符合预期；关键用例必须可重复 ≥3 次结果一致。

**通用必录字段（所有转换/故障用例）**：时间、模式、阶段枚举、σ（目标/实际）、μ、V_a、姿态、高度/下沉率、各电机指令、油门融合值、电机饱和标志、failsafe/ABORT 事件及触发源。参数名与控制律一致（TR_*、SF_*、FW_*、MC_*）。

| SIM-TR-06 | 反向转换（FW→旋翼） | 安全进入旋翼，μ→0 | REQ-F-TR-02 |

| SIM-TR-08 | 空速门槛去抖 | 空速瞬时抖动不误触发阶段切换 | REQ-F-TR-03 |

| SIM-TR-10 | 倾转补偿饱和 | 补偿后记录饱和标志；超限时触发保护 | REQ-F-TR-04 |
| SIM-TR-11 | ABORT 后禁止自动重转 | ABORT 后不自动重发转前飞 | REQ-F-TR-06 |

#### SIM-TR-01 正常正向转换（基线）

- **前置**：旋翼定点悬停 ≥30 m，V_a≈0，无故障，参数包基线，TR_WEIGHT_CURVE=1（S 曲线）。
- **步骤**：发转前飞指令 → 等待 AIRSPEED_WAIT → 模型加速至 V_a≥TR_ASPD_MIN 并保持 → 进入 TRANS_TIMER → 至 TRANS_DONE。
- **期望-行为**：阶段依次 IDLE→AIRSPEED_WAIT→TRANS_TIMER→TRANS_DONE；σ 按 TR_TILT_RATE_UP 限速；μ 沿 S 曲线 0→1 单调。
- **期望-性能**：|Δφ|、|Δθ| <5°（过渡期间峰值）；高度波动 <10 m；无电机长时间饱和（饱和标志占比 <10% 时间）。
- **期望-日志**：阶段切换事件齐全；σ/μ 连续无跳变；完成时 σ≈1、μ=1。
- **判废**：失控、触地、阶段回跳、μ 非单调、ABORT 误触发。

#### SIM-TR-02 空速不足触发 ABORT

- **前置**：同 SIM-TR-01。
- **步骤**：进入 TRANS_TIMER 后（σ≈0.3~0.5），将空速注入限制为 V_a = TR_ASPD_MIN − 2（持续）。
- **注入**：空速传感器/模型上限钳位，持续 >TR_ABORT_ASPD_T。
- **期望-行为**：阶段→ABORT；σ 以 TR_TILT_RATE_DN 回 0；μ→0；切 TR_ABORT_ACT 模式（首飞配旋翼降落/悬停）。
- **期望-日志**：ABORT 事件，触发源=空速不足；记录当时 V_a/σ/μ/姿态；回退后高度环恢复。
- **判废**：ABORT 未在 TR_ABORT_ASPD_T+1 拍内触发；触地；ABORT 后又自动重转（关联 SIM-TR-11）。

#### SIM-TR-03 姿态超限 ABORT

- **前置**：同 SIM-TR-01。
- **步骤/注入**：TRANS_TIMER 中段施加扰动使 |φ| 或 |θ| > TR_ABORT_ATT 并持续 >TR_ABORT_ATT_T。
- **期望**：ABORT，触发源=姿态超限；其余同 SIM-TR-02。
- **判废**：姿态已超限但未 ABORT。

#### SIM-TR-04 遥控/开关中断转换

- **前置**：同 SIM-TR-01。
- **步骤**：AIRSPEED_WAIT 与 TRANS_TIMER 各做一次：拨"中断转换"开关。
- **期望**：1 拍内置 ABORT（不等持续时间防抖），σ→0、μ→0、回旋翼保护模式。
- **判废**：响应滞后 >2 个控制周期；任一阶段未响应。

#### SIM-TR-05 转换超时

- **步骤 A（默认）**：让转换迟迟不满足完成条件（空速/姿态临界），运行至 >TR_FAIL_TMO。  
  **期望**：阶段→ABORT，触发源=超时。
- **步骤 B（配置强制完成）**：置强制完成位，但令空速/姿态不满足安全条件。  
  **期望**：不得强制完成，仍回退（安全条件优先）。
- **判废**：超时无动作；不安全条件下仍强制完成。

#### SIM-TR-06 反向转换

- **步骤**：固定翼平飞中切旋翼模式。
- **期望**：σ 以 TR_TILT_RATE_DN 回 0；μ→0；旋翼高度/姿态环接管；无空速门槛；高度波动可控。
- **判废**：反向转换需空速才动作；接管瞬间姿态发散。

#### SIM-TR-07 转换中加风

- **注入**：TRANS_TIMER 全程施加 5–10 m/s 常值风 + 阵风（与 SIM-RB-07 联动）。
- **期望**：要么带风完成（性能可能降级但 <5°/<10m），要么触发任一 ABORT 判据安全回退；不允许失控。
- **判废**：既不完成也不 ABORT、姿态持续发散。

#### SIM-TR-08 空速门槛去抖

- **注入**：V_a 在 TR_ASPD_MIN 上下快速抖动（周期 <TR_ASPD_HOLDT）。
- **期望**：不进入 TRANS_TIMER，阶段稳定停在 AIRSPEED_WAIT；μ 不变。
- **判废**：阶段来回跳变。

#### SIM-TR-09 油门融合（全倾转构型）

- **步骤**：正常转换，记录 T_mc、T_fw、σ、融合后 T_cmd。
- **期望**：T_cmd = T_mc(1−r)+T_fw·r，r=(σ−σ_asp)/(1−σ_asp)；曲线连续无阶跃；σ=σ_asp 时全旋翼、σ→1 时全固定翼。
- **判废**：油门阶跃 >阈值（如 0.15/拍）；融合方向反。

#### SIM-TR-10 倾转补偿与饱和

- **步骤**：在大姿态需求/大油门下转换，迫使 1/cos 补偿放大。
- **期望**：垂直升力分量维持（不掉高）；任一电机 >1 时整体等比缩放并置饱和标志；饱和持续超阈值时联动高度/姿态 ABORT。
- **判废**：无补偿导致明显掉高；饱和无日志；饱和后无保护。

#### SIM-TR-11 ABORT 后禁止自动重转

- **步骤**：SIM-TR-02 触发 ABORT 回旋停后，不再给新指令，观察 ≥30 s。
- **期望**：保持旋翼保护模式，不自动重新发起转前飞。
- **判废**：自动重转。

#### SIM-FI-ASPD 空速失效 / 失速保护（对齐控制律 §7.2）

- **前置**：固定翼巡航或 TRANS_TIMER 中段。
- **注入 A（空速失效）**：空速读数卡死或丢帧。
- **期望 A**：禁止新发起转前飞；若已在转换中按空速相关判据进入 ABORT 或降级；日志标记空速健康差。
- **注入 B（失速）**：V_a 降至 <FW_ARSPD_STALL 持续 T_stall。
- **期望 B**：解除上仰需求、油门推保护值；高度继续掉则转旋翼构型（若允许）；旋翼模式下不触发失速保护。
- **判废**：失速无动作；旋翼模式误触发失速保护。

#### SIM-FI-MOT-A/B/C 单电机失效（对齐控制律 §7.3）

| 子用例 | 前置 | 注入 | 期望-行为 | 判废 |
|--------|------|------|-----------|------|
| MOT-A | 旋翼悬停 20 m | 关断 1 号电机推力 | 检测标志置位；若可维持姿态则重分配并保护降落；不可维持则迫降程序；日志记触发源 | 未检测；继续航线 |
| MOT-B | TRANS_TIMER 中段 | 关断 1 号电机 | **立即 ABORT**（同 §5.7 动作序列）；不完成前飞；回旋翼后保护降落 | 继续转换；无 ABORT |
| MOT-C | 固定翼平飞 | 关断前飞动力一侧 | 舵面补偿；就近迫降；**不**主动转旋翼（除非推力足够且策略允许） | 盲目转旋翼导致失速 |

**关键路径**：SIM-FI-MOT-B 二期必过（出门准则）。

#### SIM-FI-ALT 高度异常（按阶段）

- **注入**：人为增大下沉率或注入高度异常。
- **期望**：转换中→ABORT；固定翼→增油门/低头；旋翼→高度环全权限；近地异常下沉→自动降落（高度可信时）。
- **判废**：各阶段无差异化动作。

## 6 通过 / 失败准则

### 6.1 单条

- **通过**：满足期望-行为/性能/日志三列 + 无失控 + 关键事件齐全 + ≥3 次可重复  
- **条件通过**：逻辑正确但性能略超标，须开问题单并限飞  
- **失败**：失控、触地、错误模式、ABORT 应动未动、ABORT 后自动重转、阶段来回跳变  

### 6.2 出门（二期评审）

| 类别 | 要求 |

## 附录 C 场景配置模板（扩充）

```text
# ---- 正常转换 ----
SCN_SIM-TR-01:
  init: hover 30m, armed, MC_POS, TR_WEIGHT_CURVE=1
  steps: request_fw_transition
  expect:
    phases: WAIT -> TIMER -> DONE
    attitude_peak_deg: <5
    alt_excursion_m: <10
    mu: S-curve 0->1 monotonic
    sigma: rate-limited by TR_TILT_RATE_UP

# ---- 空速不足 ABORT ----
SCN_SIM-TR-02:
  init: same as TR-01
  inject: after sigma in [0.3,0.5], clamp Va = TR_ASPD_MIN-2 for >TR_ABORT_ASPD_T
  expect:
    phase: ABORT within TR_ABORT_ASPD_T+1 cycle
    trigger: airspeed_low
    sigma -> 0 @ TR_TILT_RATE_DN; mu -> 0
    mode: TR_ABORT_ACT
    no auto re-transition for 30s

# ---- 人工中断 ----
SCN_SIM-TR-04:
  init: same as TR-01
  inject: abort_switch at WAIT and at TIMER (two runs)
  expect: ABORT within 1 control cycle both times

# ---- 油门融合 ----
SCN_SIM-TR-09:
  init: full-tilt configuration
  log: T_mc, T_fw, sigma, sigma_asp, T_cmd
  expect: T_cmd = T_mc*(1-r)+T_fw*r, r=(sigma-sigma_asp)/(1-sigma_asp)
  fail_if: |dT_cmd| per cycle > 0.15

# ---- 转换中单电机 ----
SCN_SIM-FI-MOT-B:
  init: TRANS_TIMER mid
  inject: motor1_thrust = 0
  expect: immediate ABORT; no continue-to-FW; protect land after VTOL recover
```
