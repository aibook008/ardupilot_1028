## 1 引言

### 1.1 编写目的

本文档将《倾转旋翼验证机飞控系统采购技术协议书》中的技术要求形式化为可追溯、可验证的需求条目，作为系统设计、实现、测试与验收的唯一基线。未列入本文档且未经变更控制批准的内容，不作为交付与验收依据。

### 1.2 项目背景

- **机型**：约 300kg 级倾转旋翼验证机  
- **目标**：交付飞控计算机、机载软件、地面站、半实物仿真系统及配套文档，支持旋翼、转换、固定翼全模态飞行与试飞验证  
- **阶段**：一期设计选型（2026-08-31）→ 二期仿真与缩比机（2026-09-30）→ 三期验证机首飞（2026-10-31）→ 四期全模态与齐套交付（2026-12-31）

### 1.4 引用文件

## 2 系统概述

### 2.1 系统边界

| 范围 | 内容 |
|------|------|
| 在内 | 飞控计算机及机载软件、主备数据链机载端、GNSS/空速等配套、遥控器、半实物仿真系统、地面站软件、二次开发接口与文档 |
| 在外 | 机体结构、动力装置本体、气动外形设计、空域与适航取证主体责任（甲方总体） |
| 协作 | 甲方提供气动/CFD/风洞数据、缩比机与验证机平台、试飞空域；乙方负责飞控设计、控制律、软件、仿真与试飞支持 |

### 2.2 运行环境（摘要）

- 工作温度：**-40℃ ~ +60℃**（飞控计算机）  
- 总重：飞控计算机 ≤ 2kg  
- 供电：机载低压直流（详见 ICD）  
- 振动/电磁：按航空机载设备常规要求，具体等级在详细设计中固化  

### 2.3 用户角色

试飞员、地勤/机务、二次开发工程师、甲方总体与质量、适航/合规对接人员。

### 2.4 假设与约束

| 编号 | 假设/约束 | 影响 |
|------|-----------|------|
| A-01 | 甲方于二期 W3 前提供可用气动数据 | 仿真保真度与过渡段预整定 |
| A-02 | 缩比机、验证机按开发计划节点到位 | 试飞里程碑 |
| A-03 | 工业级宽温飞控板可在 W3 前回片或有等效温控方案 | 硬件联试 |
| A-04 | Remote ID / UOM 对接环境四期前可用 | 合规验收 |
| C-01 | 机载软件为确定性实时单主循环架构 | 架构约束 |
| C-02 | 二次开发不得破坏故障保护与解锁安全逻辑 | 安全约束 |

## 6 非功能需求

### 6.1 可靠性与安全（REQ-NF-S）

- 分层故障保护：告警 → 降级 → 返航 → 迫降  
- 关键安全需求见 REQ-F-SF / REQ-F-TR-05/06  
- 一期完成 PHA/FMEA 初版，三期前关闭高风险项验证  

### 6.2 实时与确定性（REQ-NF-R）

- 单主循环 + 固定频率任务表；禁止控制路径上的无界阻塞  
- 任务时间预算可配置/可监测  

### 6.3 可维护性（REQ-NF-M）

- 参数化配置，支持地面保存与版本管理  
- 全量日志支持离线分析  

### 6.4 可扩展性（REQ-NF-E）

- 预留传感器余度与板级余度扩展点  
- HAL 支持新传感器/新输出类型扩展
