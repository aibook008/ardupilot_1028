## 2. 垂起调通（日志 08 → 19）

### 2.1 倾转一开始不在垂直

**现象**：起飞瞬间 `TILT.Tilt≈90°`，`C13/C14≈2000`（前飞端），之后才收到垂直。

**根因**：不在 VTOL 模式且未开 `DISARMED_TILT_UP` 时，`Tiltrotor::continuous_update()` 把倾转 slew 到前飞。GUIDED/AUTO 若未走 VTOL takeoff，会表现为「一开始就往前倾」。

**做法**：先在 **QHOVER / QLOITER** 验证；需要时再开相关 `Q_OPTIONS`。

### 2.2 推力与低头

- 默认 SITL 模型推力偏弱，飞不起来或易失控。
- 引入 / 标定 `Tools/autotest/models/jt20.json`（质量、`velocity_max`、`A_eff`、桨位等）。
- 推力中心偏后导致低头：按 `motorN_position` 修正后，低头从约 **−70°** 降到约 **8°**（`00000018` / `00000019`）。

推力中心粗算：对各电机位置做推力加权平均（SITL 在 `motorN_position` 处施加推力）。

### 2.3 偏航失控：Lua yaw 与 json `motorN_yaw` 必须同号

| 阶段 | Lua yaw | SITL yaw 来源 | 结果 |
|------|---------|---------------|------|
| 最初 | 与 `jt20_motors[]` 标签一致 | 构造函数 CW/CCW | `00000010` 狂转 ~−440°/s |
| 取反 Lua | 翻转 | 仍构造函数 | `00000011/13` 偏航基本可控 |
| 上 json 名义 yaw | 仍翻转 | json 覆盖成名义符号 | `00000018` 又转 ~−180°/s |
| json 与 Lua 同号翻转 | 翻转 | json 也翻转 | `00000019` 平均 −4°/s |

**原则**：对齐的是**实际力矩方向**，不是 CW/CCW 字面标签。SITL 中有：

```text
rotor_torque ∝ thrust_vector * yaw_factor * command * yaw_scale * (-1)
```

json 的 `motorN_yaw ≠ 0` 会覆盖构造函数；上 json 后必须与**当前 Lua** 同号，不能跟 SDF/`jt20_motors` 标签死磕。反扭矩权威还 ∝ `diagonal_size`，json 对角线远大于默认时，符号一旦反了会越纠越转。

### 2.4 里程碑：`00000019` QLOITER 稳定

| 指标 | 数值 |
|------|------|
| 高度 | max ~36 m，可悬停 |
| `ThO` | mean ~0.50，基本不打满 |
| Pitch / Roll max | ~8° |
| 倾转 | 全程 ~0°（垂直） |
| 偏航 | 慢漂 ~−4°/s（非失控） |

## 4. VTOL takeoff → 前飞：先对齐航向再倾转

### 4.1 问题（`00000020`）

AUTO Takeoff→WP：到高后立刻过渡，过渡开始时航向与航线差约 **−75°**，边倾转边飞出再慢慢修航向。

根因：非 vectored（`Q_TILT_TYPE=0`）在 `TRANSITION_AIRSPEED_WAIT` 里只 `reset_yaw_target_and_rate()`——**锁当前航向，不对齐下一航点**。即便 vectored，`update_yaw_target()` 也是锁过渡开始瞬间航向，仍不是「先转到下一 WP」。

固定翼巡航段高度保持本身基本正常；问题在过渡前/中航向。

### 4.2 做法（任务层门控）

高度到位后先 yaw 对齐下一航点，进门限后再 `transition->restart()`。

参数：`Q_OPTIONS` 相关 bit + `Q_TF_YAW_ERR`（如 15°）。

### 4.3 验证（`00000022`）

MSG 可见：

```text
VTOL takeoff: aligning yaw to next WP
waiting yaw align err=-81 deg
yaw aligned, transitioning    ← 约 2.3s 后才 Transition started
```

对齐期间 `TILT` 保持垂直；对齐完成才开始倾转。对比 `00000020` 到高就直接 Transition。

文档：`docs/vtol_jt20.md` §9.7。

## 5. 切 FW 掉高与 TECS（`00000023` 等）

### 5.1 真实掉高约 5 m

用 `AHR2` / `BARO` / `TECS.h`（不要用进 FW 后停录的 `QTUN.Alt`）：

- FW 入口附近 BARO ≈19.8 m → 约 1.5 s 后掉到 ≈15.0 m
- **掉高约 5 m**（早期用 QTUN 误判成 0.65 m）

最严重掉高发生在 TIMER→DONE 旋翼撤升力、TECS 油门仍在衰减（尚未到 0）的窗口；之后 TECS=0 段还有二次掉高。

### 5.2 代码级机理（摘要）

1. WAIT 反复 `reset_throttle_I()` → 进 FW 时积分为 0，接棒慢
2. TECS 油门 = PD+FF+积分，切换瞬间三项偏低
3. `THR_SLEWRATE` 限制油门爬升速率
4. 旋翼侧 `last_throttle×(1−t/T)` 开环时间衰减；JT-20 有外四永久 VTOL，**不走** TIMER 内 MC↔TECS 混合

一句话：旋翼升力撤得快，TECS 前飞油门爬得慢 → 总推力塌陷 → 掉高。

### 5.3 日志坑

| 阶段 | 高度看什么 |
|------|------------|
| VTOL / WAIT / TIMER | `QTUN.Alt` |
| **FW 及之后** | **`AHR2.Alt` / `BARO.Alt` / `TECS.h`** |

`QTUN` 在 Trn=2 入口附近停录，把最后一条当持续值会误判「高度稳住」。

### 5.4 TECS=0 段怎么看

| 想看 | 日志字段 |
|------|----------|
| 前向油门 | `TECS.th` / `CTUN.ThO` / `AETR.Thr` |
| 升降舵 | `AETR.Elev` / `RCOU.C2` |
| 垂直速率 | `CRt` |
| 倾转 / 电机 | `RCOU.C13–14` / `C5–12` |

TECS=0 常是能量管理下的「滑翔」（动能富余 → 油门归零、用俯仰管空速），与失效要区分开。

### 5.5 缓解方向

- `AIRSPEED_MIN` 略提高（如 13→15–16），机翼升力更大再撤 VTOL
- `Q_TRANSITION_MS` ↑、`Q_TILT_RATE_UP` ↓
- `THR_SLEWRATE` ↑ 或 0
- 代码级：WAIT 不清 TECS 积分 / 让 JT-20 也走混合淡入

写入：`docs/throttle_calculation.md`（含切 FW 掉高专节）。

### 5.6 `QTUN.ThI` 在过渡中的形状

大致：爬升偏高 → 对齐/悬停回落到 hover → WAIT 倾转瞬间因 `assist_climb` + `1/cosθ` 再抬一把 → 稳住 → TIMER 时间衰减 → DONE 后 VTOL spool 关。

`ThI` 是混控前集体油门；通道级看 `RCOU` / `MOTT`。倾转后内四可打满、外四随 TIMER 明显下降。过渡期 pitch 限幅与 `Q_TRAN_PIT_MAX` 等相关（分段限幅，不是全程卡死在该值）。

## 6. 电机归一化油门与功率

### 6.1 `MOTT` 日志（新加）

调用顺序：

```text
output_armed_stabilizing()   // 混控 → _thrust_rpyt_out[i]
thrust_compensation()        // JT-20: tilt_compensate，含 1/cosθ
★ MOTT 记录 _thrust_rpyt_out[i]（0~1）
thrust_to_actuator() → PWM → RCOU
```

- 文件：`libraries/AP_Motors/AP_MotorsMatrix.cpp`
- 日志名：`MOTT.Mot1…Mot8`
- 频率：armed 约 50 Hz

| 量 | 含义 |
|----|------|
| `QTUN.ThI` | 集体需求 |
| `MOTT.Mot*` | 各电机最终 0~1（转 PWM 前） |
| `RCOU.C5–C12` | 对应 PWM |

旧 log（无 MOTT）用 `RCOU` + `Q_M_SPIN_MIN/MAX` + `Q_M_THST_EXPO` 反推归一化推力。

### 6.2 功率底稿

- 文档：`docs/jt_power_anaylisis.md`
- 脚本：`docs/scripts/jt20_power_from_log.py`
- 对比：`00000023`（RCOU 反推）vs `00000024`（MOTT）
- 模型与 `jt20.json` / SITL 盘模型一致：`v_out`、`T=0.5ρA(v_out²−v_in²)`、`P≈power_factor·T`（气动功率代理；SITL `ESC.Curr` 不可信）

整机/气动参数参考：`docs/数据库_v2.xlsx`。
