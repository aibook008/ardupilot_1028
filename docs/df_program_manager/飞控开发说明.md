# 倾转旋翼验证机飞控系统 — 工作进展与下一步计划（汇报稿）


---

## 一、总体进展

飞控仿真验证阶段已基本告一段落：

- **全流程飞行仿真闭环**：垂起爬升 → 姿态/航向对齐 → 旋翼-固定翼转换 → 固定翼巡航 → 航线飞行（含转弯），完整任务链在仿真中稳定复现；
- **高保真动力学模型**：基于电机台架实测数据与气动数据建立动力/气动模型，仿真结果具备工程参考价值；
- **转换安全策略增强**：针对大重量倾转旋翼的转换过程，自研"倾转角-空速"安全门控策略，已纳入机载软件；
- **功率匹配分析**：各飞行阶段功率需求已量化，并与电池规格完成对照；
- **技术协议需求逐条对照**：形成功能覆盖清单与差距清单，指导后续开发。

同时，仿真过程中暴露了一批问题与风险（见第四节）。**所有问题均已定位、均有明确处置路径**，将在实机飞行前逐一归零，这也是制定飞行计划的重要输入。

| 3 | 转换安全门控策略 | 建立"倾转角-空速"配对机制：空速未达到对应门槛前不允许继续倾转，从机制上防止转换过程垂向推力不足 |
| 4 | 功率走廊量化 | 垂起爬升 ~95kW、转换 ~76-113kW、巡航 ~8kW，与电池规格逐段对照；起飞瞬间功率尖峰成因已定位（见风险 P8） |

**阶段结论**：控制律架构（旋翼串级控制 + 固定翼导航/能量控制 + 转换状态机）在 350kg 级模型上得到验证，技术路线成立。

## 四、问题与风险（飞行计划编制重点）

> 以下风险均有仿真依据支撑。**处置原则：仿真阶段能归零的在仿真阶段归零，必须实机验证的纳入飞行大纲，逐项安排科目或设置限制条件。** 其中相当一部分是任何新型号首飞前必须面对的共性风险，提前识别正是仿真阶段的价值所在。

### 4.1 转换过程风险（重点）

| # | 风险 | 现状与处置 |
|---|------|-----------|
| P1 | **气动模型保真度** | 气动仿真基于总体数据库静态特性与部分动导数建立，桨-翼干扰、动态失速等效应未完全覆盖，转换段与机动工况的气动特性可能与实机存在偏差。处置：拉偏仿真覆盖不确定度区间；实机科目与仿真基准对照后逐轮修正模型；关键控制参数预留整定余量 |
| P2 | **转换中断回退路径** | 超时降级已有，主动中断回退开发中（节点 3.1）。完整转换首飞前完成，并先行验证；试飞科目包含"小角度倾转→主动回退" |
| P3 | **反向转换控制策略** | 返航/着陆过程减速-收倾转配对策略需完善（节点 1.2）。完善前返航方案采取保守策略；完成后专门科目验证 |
| P4 | **转换进入固定翼瞬间的能量管理** | 进入固定翼瞬间速度偏高或偏低都会破坏能量平衡。该问题已在仿真中解决并固化为参数基线，实机首科重点监控转换瞬间速度/油门 |
| P5 | **转换中速区横航向耦合** | 转换中速区存在横航向耦合效应，风的扰动可能加剧。转换段全程监控横航向响应，预设异常判据与人工接管手段 |
| P6 | **转换逻辑对空速测量的依赖** | 转换安全门控以空速为核心输入，空速标定误差直接影响门控有效性。空速管标定列入地面必做科目 |
| P7 | **转换过程高度损失** | 升力/推力交接存在固有高度损失，当前仿真结果处于可控、合理的工程范围，主要贡献因素已定位，持续优化中。实机转换科目设置最低转换高度限制，确保安全裕度 |

### 4.2 动力与能源风险

| # | 风险 | 现状与处置 |
|---|------|-----------|
| P8 | **起飞瞬间功率尖峰** | 仿真实测起飞瞬间功率峰值超出电池额定规格，成因已定位（起飞瞬态差动 + 集体油门尖峰），压降方案明确（节点 1.3）。实机起飞前进行动力系统台架电流复核，并确认电池管理系统保护阈值 |
| P9 | **转换段功率接近规格上限** | 转换中段功率均值较高、峰值贴近电池规格上限。转换安全门控可缩短高功率区间时长；实机全程功率监控，设置预警线 |
| P10 | **动力模型与实机偏差** | 台架数据不包含桨-翼干扰等实机效应，实机悬停油门/功率需求可能存在偏差。旋翼首飞第一科目即设置悬停油门、功率实测，与仿真基准对照后修正模型 |

### 4.3 实机特有风险（仿真无法覆盖，地面试验专项安排）

| # | 风险 | 处置 |
|---|------|------|
| P11 | 结构振动与电磁干扰 | 全机联试专设振动测试、CAN 总线干扰测试；飞控减振与线缆屏蔽方案确认 |

## 五、实机科目与仿真对照（等效性验证）

> **核心原则：仿真调出来的不是"参数"，是"基准"。实机飞行不是重新调一轮，而是逐科目与仿真基准对照；偏差超限即回到仿真复现、归因、修正后再对照。**

### 5.1 对照科目表

| 科目 | 仿真基准 | 实机对照判据 | 超差处置 |
|------|---------|-------------|---------|
| 悬停油门/功率 | 悬停油门 ≈ 推重比对应值；悬停功率 ~95kW | 偏差 <10%（油门）/<15%（功率） | 修正动力模型，重新校准仿真基准 |
| 转换轨迹 | 转换全程沿"倾转角-空速"走廊内进行 | 实测轨迹全程走廊内 | 收窄走廊参数或限制倾转速率 |
| 转换高度损失 | 仿真基准值（可控范围内） | 实测不超出仿真基准并留有裕度 | 回仿真做能量归因后优化 |
| 巡航配平 | 巡航 55m/s、配平姿态与舵位已知 | 空速偏差 <5% | 修正升阻特性，更新仿真 |
| 航线转弯 | 40° 坡度限幅、不掉高不超速、跟踪误差 ~1° | 同指标复测 | 参数回滚排查 |
| 功率走廊 | 垂起 95 / 转换 76-113 / 巡航 ~8 kW | 分段实测对照 | 修正功率模型，重估续航与电池裕度 |
| 反向转换 | 反向转换控制策略完善后的仿真基准 | 实测与仿真基准一致 | 归零前不开放自动返航 |
| 自主起降 | 仿真基准偏移量 | 实测与仿真基准一致 | 检查定位精度与着陆逻辑 |

### 5.2 偏差闭环流程

```
实机飞行 → 日志 → 与仿真同口径分析 → 与仿真基准对照
    ├─ 判据内 → 科目通过，进入下一科目
    └─ 超差   → 偏差定位（模型 / 传感器 / 参数）
              → 在仿真中复现该偏差 → 归因修正 → 更新基准 → 重新对照
```

- 每个科目形成一次"仿真 ↔ 实机"闭环，逐科目累积**等效性证据链**，作为仿真测试报告与飞行试验报告的核心内容；
- 全部科目通过后，即完成仿真模型与实机的一致性确认，支撑后续包线扩展与试飞加速。
