## 1 目的与结论先行

### 1.1 目的

澄清工程概念「倾转走廊」（θ–V 包线）与 ArduPilot QuadPlane/Tiltrotor **实际实现**之间的差距，作为：

- 对内：补缺与仿真设计依据  
- 对外：控制律/特性分析中「一期近似 vs 二期增强」的表述依据（脱敏后写入 phase1 文档）

### 1.2 结论先行

| 判断 | 说明 |
|------|------|
| **APM 没有完整倾转走廊** | 不存在「当前倾转角 θ → 查 V_min(θ)/V_max(θ) → 出界限幅/调度」 |
| **有一维门槛 + 安全网** | `AIRSPEED_MIN` 转换门槛、`Q_ASSIST_*`、倾转**速率**限制、转换超时失败、油门随倾转融合 |
| **对 300kg / 协议转换安全不够** | 门槛是全局常数，不是随 θ 变化的包线；ABORT/超时偏事后，走廊偏事前 |
| **补缺路径清晰** | 气动表（甲方）→ 监视器 → 出界处置 →（可选）σ=f(V) 调度；见 catch-up 计划 |

## 2 完整倾转走廊：工程定义

### 2.1 二维包线

```
空速 V
  ▲
  │          ╱ V_max(θ)  结构/桨叶/颤振/下洗上限
  │         ╱
  │        ╱    ████ 允许飞行区 ████
  │       ╱
  │      ╱_____ V_min(θ)  升力不足/失速/掉高下限
  └──────────────────────────► 倾转角 θ
       0°(垂直)              90°(水平)
```

| 边界 | 物理含义 | 违反后果 |
|------|----------|----------|
| **V_min(θ)** | 该倾转角下，机翼升力 + 旋翼垂直分量能否托住重量并保持可控 | 掉高、大迎角、失控 |
| **V_max(θ)** | 该倾转角下结构载荷、桨叶、颤振、下洗冲击等限制 | 过载、机构损坏 |

倾转进度 σ∈[0,1] 与物理角：θ = σ · 90°（连续倾转构型；若机械行程非 0–90，按实机标定映射）。

### 2.2 控制层通常还要做的三件事

| 层次 | 内容 |
|------|------|
| **监视** | 每拍检查 (θ, V) 或 (σ, V_a) 是否在带内（含 margin） |
| **处置** | 出下限：禁止继续增大 σ / 强制加速 / ABORT；出上限：限油门 / 强制减小 σ |
| **调度（可选）** | σ_cmd = f(V_a) 沿走廊中线推进，而不是开环时间表倾转 |

### 2.3 与「转换状态机」的关系

- **走廊**：气动/结构允许的 **状态集合**  
- **状态机**：在集合内如何从旋翼构型走到固定翼构型的 **程序**  

没有走廊约束的状态机，可以在程序上“合法”地走进气动危险区（例如倾转已经很大、空速仍偏低）。

## 3 ArduPilot 现有相关机制（能力地图）

> 下列为内部对照；对甲文档不得出现参数原名与源码路径，应改写为自研逻辑名（见 §7）。

### 3.1 正向转换：空速门槛（一维）

**位置**：`SLT_Transition::update()`，`TRANSITION_AIRSPEED_WAIT`

**行为摘要**：

- 悬停/旋翼辅助维持，直到空速估计有效且 **V > `AIRSPEED_MIN`（`aparm.airspeed_min`）**  
- 达标后进入 `TRANSITION_TIMER`，并记录 **`airspeed_reached_tilt`**（刚达标时的倾转角）  
- TIMER 内按 `Q_TRANSITION_MS`（transition_time）衰减旋翼油门、混合控制权  

**走廊语义**：仅一条**水平**门槛线 V = AIRSPEED_MIN，与当前 θ **无关**。

### 3.2 Q_ASSIST：固定翼模态下的旋翼补力

**位置**：`VTOL_Assist::should_assist()`

**触发（可并存）**：

| 条件 | 参数 | 含义 |
|------|------|------|
| 空速过低 | `Q_ASSIST_SPEED` | V < 阈值则辅助 |
| 姿态误差大 | `Q_ASSIST_ANGLE` + delay | 包线/跟踪误差 |
| 近地过低 | `Q_ASSIST_ALT` | 高度辅助 |
| 强制 | 遥控辅助开关等 | 人工 |

辅助为真时，过渡逻辑可回到「空速等待」类行为（旋翼再出力）。

**走廊语义**：飞慢了/飞歪了就帮忙——**安全网**，不是 θ–V 查表。

### 3.3 倾转速率限制（dθ/dt，不是 θ–V）

**位置**：`Tiltrotor::slew` / `tilt_max_change`  
**参数**：`Q_TILT_RATE_UP`、`Q_TILT_RATE_DN`

限制倾转角变化快慢，**不**限制「当前 θ 允许的 V」或「当前 V 允许的 θ」。

### 3.4 转换失败：时间维

**参数**：`Q_TRANS_FAIL`、`Q_TRANS_FAIL_ACT`、选项 `TRANS_FAIL_TO_FW`

超时 → QLAND/QRTL，或（选项 + 地速条件）强制进入 TIMER。  
管「拖太久」，**不管**「(θ,V) 出包线」。

### 3.5 全倾转油门融合（控制混合）

**位置**：TIMER 段，全倾转且无独立 FW/VTOL 电机时  

按 `current_tilt` 在 `airspeed_reached_tilt` → `fully_forward` 之间插值，混合旋翼油门与前飞油门。

**走廊语义**：推力分配假设已在合理空速上；**不检查**该 θ 下 V 是否合法。

### 3.6 倾转补偿 1/cos 等

**位置**：`Tiltrotor::tilt_compensate*`  

补偿升力分量与偏航机制迁移，属于**混控物理**，不是包线监视。

### 3.7 反向转换

切 VTOL 模式后倾转回垂直，**无**「必须先减速到某 V 再允许某 θ」的配对约束。

### 3.8 能力总表

| 走廊要素 | APM | 说明 |
|----------|-----|------|
| V_min(θ) 曲线/查表 | ❌ | 仅全局 AIRSPEED_MIN |
| V_max(θ) 曲线/查表 | ❌ | 无 |
| 出下限事前限 σ / 强制加速 | ❌ | 有事后超时/失败与（文档规划的）ABORT |
| 出上限限油门 / 收 σ | ❌ | 无 |
| σ_cmd = f(V) 中线调度 | ❌ | 倾转与空速基本解耦推进 |
| 固定翼低速旋翼辅助 | ✅ | Q_ASSIST |
| 倾转速率限制 | ✅ | RATE_UP/DN |
| 转换空速门槛 | ✅ | AIRSPEED_MIN |
| 超时失败 | ✅ | TRANS_FAIL |
| 油门随倾转融合 | ✅ | 全倾转 TIMER |
| 主动 ABORT 多判据 | ⚠️ | 原生偏超时/QLAND；项目文档规划增强 |

## 4 概念对照图

```
完整倾转走廊                    APM 近似

V_max(θ) ──── 曲线              （无）
   ██ 允许区 ██                   AIRSPEED_MIN ─── 水平门槛
V_min(θ) ──── 曲线              Q_ASSIST_SPEED ─ 辅助线（FW 模态）
   θ →                          倾转速率 ──────── 限制 dθ/dt
                                超时失败 ──────── 时间维
                                油门融合 ──────── 分配，非包线
```

**一句话**：APM 用「等够空速再交权 + 慢了就辅助 + 倾转别太快」**蹭**走廊边缘；**不等于**已实现倾转走廊。

## 5 与项目已写 ABORT / 控制律的关系

| 手段 | 时机 | 与走廊关系 |
|------|------|------------|
| AIRSPEED_MIN 门槛 | 转换中段入口 | 全局 V_min 的粗糙代理（与 θ 无关） |
| 文档规划的 ABORT（空速不足/掉高/姿态） | 事后逃生 | ≈ 撞下限后的处置，非事前 (θ,V) 约束 |
| Q_ASSIST | FW 模态低速 | 走廊外低速的补力，不生成 θ 指令约束 |
| 完整走廊监视+调度 | 事前 | **缺口**；catch-up 主目标 |

大飞机更需要**事前**把轨迹压在走廊内；仅靠 ABORT 是「掉下来再救」。

## 6 缺口分级与补缺形态

### 6.1 缺口分级

| 级别 | 缺口 | 风险 | 建议阶段 |
|------|------|------|----------|
| G1 | 无 V_min(θ)/V_max(θ) 数据 | 无法定义走廊 | 等甲方气动；先用分段常数近似 |
| G2 | 无 (σ,V) 监视与出界事件 | 危险不可见、不可测 | catch-up 优先做 |
| G3 | 无出界处置（限 σ / 限 V / ABORT 联动） | 能看见却刹不住 | 紧接 G2 |
| G4 | 无 σ=f(V) 调度 | 开环时间表可能贴边或穿出 | 仿真验证后增强 |
| G5 | 反向转换无减速–收倾转配对 | 高速大倾转回垂直风险 | 三期试飞前 |

### 6.2 最小可行增强（设计级，非本仓库必改代码）

```
每拍：
  Vmin = table_or_piecewise(σ)
  Vmax = table_or_piecewise(σ)
  if V_a < Vmin - margin:
      forbid_increase_σ
      request_accelerate or raise ABORT_corridor_low
  else if V_a > Vmax + margin:
      limit_throttle
      command_decrease_σ
  else:
      allow slew σ; optional σ_cmd = corridor_midline(V_a)
```

分段近似示例（数值占位，气动数据替换）：

| σ 区间 | V_min (m/s) | V_max (m/s) |
|--------|-------------|-------------|
| 0–0.33（~0–30°） | 0 | V1 |
| 0.33–0.67 | V2 | V3 |
| 0.67–1.0 | ≈1.1×Vs | V4 |
