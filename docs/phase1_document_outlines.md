- 航点管理、任务上传下载、断点续飞、返航点

- 多通道解析、失控保护、主备数传切换

- 低电量 / GNSS 丢失 / RC 中断 / 电子围栏

- 设备监控与余度管理

### 3.7 合规与识别（REQ-F-ID-xxx）
- 实名登记与激活校验

- 识别失效处置

### 3.8 二次开发支持（REQ-F-API-xxx）
- 飞行状态获取 API
- 控制指令注入 API
- HAL 抽象、示例工程、中文文档

### 3.9 地面站（REQ-F-GCS-xxx）
- 任务规划、实时曲线、参数管理、双平台（Win/Ubuntu）

### 3.10 仿真与验证支持（REQ-F-SIM-xxx）

## 3 模块划分与职责

| 模块 | 职责 | 对外接口 | 依赖 |
|------|------|---------|------|
| HAL/BSP | 时钟/总线/PWM/SD/看门狗 | 板级 API | 硬件 |
| 传感器驱动 | IMU/磁/气压/GPS/空速/电流 | 采样缓冲 | HAL |
| 状态估计 | 多 lane EKF、一致性检查 | 姿态/位置/速度/风 | 驱动 |
| 旋翼控制 | 姿态/位置串级 | 归一化力矩 | 估计 |
| 固定翼控制 | L1 + TECS + 舵面 PID | 舵面指令 | 估计 |
| 过渡管理 | 三阶段状态机、权重混合 | 混合输出 | 两套控制 |
| 倾转与混控 | 倾转速率、补偿、混控矩阵 | 通道指令 | 过渡 |
| 飞行模态 | 各模式 enter/run/exit | 模式切换 API | 控制律 |
| 故障保护 | 分层 failsafe | 降级/模式强制 | 全系统 |
| 任务导航 | 航点、任务状态机 | 导航指令 | 估计 |
| 通信 | 遥测、遥控、地面站协议 | 消息收发 | HAL |
| 参数/日志 | 持久化、记录、回放 | 读写 API | 存储 |
