## 3. 当前卡点：FW 交接后坠地（184）

**现象**：FW done(t=94.75) 后 5 秒坠地。TECS.Th=0 持续 8 秒（92.5→100.5），RCOU C5-C12 全部 1000。

**数据链**：
```text
t=90  AS=49.4 th=1.0（正常）
t=92  AS≈55 th 衰减中
t=93-100 th=0.000，h=10.9m、hdem=20m、sp=61 vs spdem=49.4
t=100 坠地 AS 16
```

**机理（两层叠加）**：
1. **进 FW 时超速 12 m/s**（AS 61 vs 目标 49.4）→ TECS 按"超速收油门换高度"的正常能量逻辑输出 th=0 滑翔；但飞机没有多余能量预算（TIMER 段已掉 9m），AS 掉穿失速坠地。TECS 算法本身没错，是构型不匹配它的假设。
2. **构型缺 FW 动力通道**：DF-200 无独立 FW 电机（倾转桨即推进器），但 SERVO5-14 全部为 k_motor1-8(33-40)+k_motor_tilt(41)，**k_throttle(70) 无输出通道**——即使 TECS 想给油门也到不了电机。`TRANSITION_DONE` 还把旋翼 `SHUT_DOWN`（quadplane.cpp:1679-1684）。
3. **Q_ASSIST 救援全擦肩**：Q_ASSIST_SPEED=10（要 AS<10，14 就砸了）、ANGLE=60 够不到、ALT=0 禁用。

**重要代码事实**（核对过）：
- `tiltrotor.cpp:115-127`：`_have_vtol_motor=true`（MOT_5..8 不在 tilt_mask=15）、`_have_fw_motor=false` → `quadplane.cpp:1655` 的 "全倾转 fw_throttle 混合分支" **未激活**，TIMER 油门是纯时间衰减 `last_throttle×transition_scale`
- `VTOL_Assist.cpp:94`：speed_assist 要求 `aspeed < Q_ASSIST_SPEED`
- `servos.cpp:613-627`：suppress_throttle 时 k_throttle 强制写 0（不走 THR_MIN）

### 闭环验证（最关键一个数）

- 纯机翼平飞所需 AS：L∝V²，67.3 m/s 时 L=0.80W → 需 **75.4 m/s TAS** 才能纯气动托住 380kg。
- **若外桨不关**：机翼只需 W−1603−33 ≈ 2090 N → 所需 AS = 67.3×√(2090/2936) = **56.8 m/s**。
- **交接点实际 AS = 56.5 m/s。**

即：**外桨保留的话，交接点恰好就是平衡点**——解释了 TIMER 段垂向基本平、一关就崩。TECS 满油门冲 77.2 m/s 目标没错，但需 ~3.5s 加速段，垂向亏空 0.25g 早已把 14.3m 高度预算花完（落地时 AS=67.3，还差 8 m/s）。

### 3.5.1 俯仰链补充：舵效本身够，是增益链把舵锁死在 5%（185 后追加分析）

用户问题："低头力矩太大，尾舵拉不起来吗？"——**舵面物理能力完全够，低头矩完全可配平；是控制链增益被 SCALING_SPEED 压掉 93%**。

**舵面物理能力（直接算，无需调参）**：

- 日志验证舵效系数：`Ma_de = qbar·c·c_m_deltae·elev_frac`，t=80 实测 9852×0.705×0.42×0.04=117 Nm ≈ 日志 121 ✓（S=5.288、c=0.705、c_m_deltae=0.42，SIM_Plane.cpp:119-159）
- 满舵（45°量程 100%）@AS60: Ma_de = **±3224 Nm**；@AS75: ±5092 Nm
- 低头矩：Ma_cg = L×0.054，AS58→−158 Nm、AS75→−201 Nm → **满舵能力是低头矩的 20 倍**

**实际链条输出（PIDP 日志逐拍核对）**：

```text
DesPitch=+6.4° vs Pitch=−3.6° → 俯仰误差 10° → 期望速率 20°/s (PTCH2SRV_TCONST=0.5)
PIDP: Tar=20.1°/s, Act≈0 rad/s, P=0.29 I=0.48→0.80 FF=1.42 (rad 系)
输出 = (FF+P+I)×100 = 219 centi-deg = 2.2° 舵 = 4.9% 量程
RCOU C2 = 1519 µs ✓ 链条闭合
力矩账: +147(舵) +22(α项) −158(CG) ≈ 0 → 俯仰卡死不动，I 积分爬升太慢
```

**根因：SCALING_SPEED=12（用户设置，config.h 默认 15），实际 AS=58**

- scaler = 12/58 = 0.207，P/I 项乘 scaler² = 0.043 → **有效增益只剩 4.3%**
- PTCH_RATE_P=0.31、FF=0.35 都是按 15 m/s 级小飞机标定的，DF-200 巡航 50-75 m/s 下全部被压扁
- I 项（IMAX=0.889 rad）在爬但 0.02/s 的速度来不及，2.2s 后坠地

**结论**：
- 不是"低头矩太大"，是舵被压到 5%。CGOffset=−0.054 引起的低头矩（0.054×L）本身很小（<5.5%W·m 量级），**满舵 20 倍裕度完全可配平**
- 修法：**SCALING_SPEED 12→45~50**（与巡航速度同量级），或等价地把 PTCH_RATE_P/RLL_RATE_P 放大 (巡航/12)² 倍。SCALING_SPEED 是全链缩放（roll/pitch/yaw 都受影响），一次改对三轴
- 气动本身正常：TIMER 段 CL·S 0.14→0.21 随 AS 增长平滑、CD·S 恒 0.037、L/D 4→5.7，俯冲段 L/D 峰值 7.5 @AS59，都在合理范围，无异常

### 3.5.2 姿态执行器切换确认（用户问题：旋翼还做姿态吗？）

- **AS≥25 后旋翼姿态差动完全退出**：`scripts/df200_motor_matrix.lua` ROLL_FLOOR=PITCH_FLOOR=YAW_FLOOR=**0.0**（64-66 行，155 试验设定），lerp_scale 从 AS_LO=15 开始线性衰减，AS≥25 全 0。185 全程 AS≥45 → RSCALE=PSCALE=YSCALE=0，旋翼只剩油门（throttle factor=1）

## 6. 历史教训（防复发）

- 改电机模型必须同步 Q_M_THST_EXPO/HOVER（飞控内部推力模型）
- 改惯量必须同步 Q_A_RAT_*_P（181 已由用户恢复大惯量+降增益）
- 手工配平值（如 CGOffset）在模型大改后必须回头核对数据源
- **SCALING_SPEED 必须与实际巡航速度同量级**（185 教训：12 vs 58 → 三轴 FW 增益被 scaler² 压掉 93%，舵"看起来"失效，实为增益链问题）
- **改参后先核对日志 PARM 再归因**（188 教训：AIRSPEED_CRUISE 改了但未生效，复飞"失败"其实是旧参数重演；下结论前先 dump PARM）
- **TECS 满油门+欠速 = 俯仰角被征用来换速度**（187 教训：这不是 bug 是能量分配律；与其压 SPDWEIGHT，不如消除欠速本身——55 巡航方案即此逻辑）
- **TECS_TIME_CONST 对 phugoid 是第一阻尼杠杆**（189→190：3→5 使高度摆幅 ±3.5m→收敛 ±0.3m）
- 上游单位 bug 已修（rot_accel /= inertia），但对上游其余机型影响未评估——若上游合并需加开关
- SITL 改动后先看 dyn log 的 sumRA 是否量纲自洽（±0.02 rad/s² 内），再谈飞行现象
