## 一、开发思路

### 1. 总体技术路线

采用**分层、解耦、库化**的飞控软件架构，按"硬件抽象 → 传感器与状态估计 → 控制律 → 飞行模态 → 作动器输出"自下而上组织；以**调度表驱动的单主循环**保证实时性与确定性；以**仿真先行、逐级验证**（SITL → HIL → 系留 → 试飞）控制首飞风险；以**参数化 + 全量日志**支撑试飞调参与问题归零。

这一路线的核心是：所有高风险逻辑（过渡状态机、混控、故障保护）先在仿真中闭环并通过故障注入验证，再上硬件，再上天；首飞前不遗留任何"上天才能验证"的逻辑。

### 2. 十二条工程原则

| # | 原则 | 工程含义 |
|---|------|---------|
| 1 | 分层解耦 | HAL/BSP 隔离硬件；驱动、估计、控制、模式、输出各层只通过明确接口交互，替换任一层不波及他层 |
| 2 | 调度表驱动 | 主循环按固定频率任务表执行，每个任务有时间预算与优先级，超时由看门狗捕获；不允许阻塞式调用 |
| 3 | 估计与控制分离 | EKF 统一输出姿态/位置/速度/风场；控制律只消费估计结果，不自行读传感器，保证单一真值源 |
| 4 | 串级 + 前馈 | 旋翼：位置→速度→角度→角速率→电机；固定翼：L1 导航→滚转、TECS→俯仰/油门；过渡段两套控制器按权重并行混合 |
| 5 | 模态化 | 每个飞行模式独立实现 `进入/周期运行/退出` 钩子，模式切换有明确的原因记录与状态初始化 |
| 6 | 过渡专用状态机 | 三阶段：等待空速达标 → 计时衰减旋翼推力并叠加固定翼舵面 → 固定翼完全接管；新增主动中断回退路径 |
| 7 | 作动器抽象 | 混控矩阵输出归一化力矩，再经通道映射到具体输出类型（PWM / DroneCAN / DShot），舵机与电机统一编号管理 |
| 8 | 参数化 | 所有可调项（PID、限幅、延时、阈值、混控系数）均为地面可配置参数，支持机上保存与版本管理 |
| 9 | 全量日志 | 控制内环、传感器原始/融合值、模式切换、故障保护触发全程高带宽记录，支持地面回放与离线复算 |
| 10 | 纵深防御 | 传感器冗余、电池/ GPS / RC / 姿态/动力分层故障保护，按"警告 → 降级 → 返航 → 迫降"逐级响应 |
| 11 | 持续集成 | 每次提交自动构建 + SITL 冒烟测试；里程碑前跑全量自动化回归，杜绝"最后一天集成" |
| 12 | 文档与代码同源 | 需求 → 设计 → 实现 → 测试用例双向可追溯，交付文档随代码版本同步更新 |

### 3. 软件层次与模块划分

```
┌─────────────────────────────────────────────────┐
│  飞行模态层  增稳/定高/定点/自动/起降/返航/过渡    │
├─────────────────────────────────────────────────┤
│  控制律层    旋翼姿态/位置环 · 固定翼 L1/TECS     │
│             · 过渡状态机 · 倾转补偿 · 混控         │
├─────────────────────────────────────────────────┤
│  估计层      EKF 多 lane · 传感器一致性检查        │
├─────────────────────────────────────────────────┤
│  驱动层      IMU/磁/气压/GPS/空速/电流/CAN/遥测    │
├─────────────────────────────────────────────────┤
│  HAL/BSP     时钟/总线/PWM/SD/看门狗/flash        │
└─────────────────────────────────────────────────┘
```

横向贯穿：参数系统、日志系统、MAVLink 通信、故障保护、调度器。

### 4. 验证阶梯（V 字左半边对应右半边）

```
需求 ──┐                                   ┌── 试飞验收
设计 ──┤                                   ├── 系统联试
       │ SITL(纯软件闭环) → HIL(真飞控+模型) │
编码 ──┤                                   ├── 桌面联调/拷机
单测 ──┘                                   └── 系留/低速滑行
```

每一级只验证本级职责：SITL 验证控制逻辑正确性，HIL 验证真实时序与接口，系留验证作动器方向与限位，首飞验证物理模型与增益。
