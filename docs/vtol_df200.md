> 代码分支：`qhz/plane_4.6.3`（Plane 4.6.3）

## 1. 构型摘要

| 项目 | DF-200 | JT-20（对照） |
|------|--------|---------------|
| 布局 | 内四倾转 + 外四固定垂起 | 同 |
| 外桨 / 内桨 | **60 in / 40 in** | ~0.6 m 量级（SITL 假设） |
| 质量 | **350 kg**（docx）；MTOW 380 kg（xlsx） | ~10 kg |
| 翼展 / 参考面积 | 7.5 m / 5.288 m² | ~2.25 m / 0.476 m² |
| 巡航速度 | 48.6 m/s | — |
| 电压等级 | ~400 V | 6S 25.2 V |
| 倾转范围 | −10°~95°（垂起 0°，前飞 90°） | SITL −90…10 约定 |

口头约定与数据库一致：**①②⑤⑥ 倾转，③④⑦⑧ 固定垂起**。

## 2. 坐标与电机编号

结构系（S）：机头参考点，**X 向后、Y 右、Z 上**。  
APM 机体：质心原点，**X 前、Y 右、Z 下**。

垂起参考重心（结构系）：`(1.900, 0, 0.483)` m。

```text
X_apm = CGx − X_s
Y_apm = Y_s
Z_apm = CGz − Z_s
angle_deg = atan2(Y_apm, X_apm)   # 机头起顺时针为正
```

数据库 ① 巡航行 Y 写成 −1315，与「右」矛盾；**垂起行取 Y=+1315（右）**，⑤/⑦ 为左（负 Y）。

### 4.1 写入的系数（xlsx 严格拟合，2026-09-17 版）

**纵向（β=0 列拟合，无改动历史）：**

| 系数 | 值 | 来源 |
|------|----|------|
| S / b / c | 5.28846 / 7.5 / 0.70513 | 基本信息 |
| CL0 / CLa | 0.311 / 6.023 /rad | β=0，α=−2…8° 拟合 |
| CD0（c_drag_p） | 0.03195 | 表内最小 CD（α≈−2°，即零升迎角附近） |
| α_stall | 0.2443 rad（~14°） | **数据截断非失速点**：CL 到 α=14° 仍在升（1.70），真实失速 ≥14° |
| Cma / Cmq | −0.487 / −19.287 | Cm–α 拟合；动导数 AVL |
| Cm0 | −0.0069 | Cm(α=0,β=0) |
| CGOffset | (−0.054, 0, 0) | aeroCenter 1.954 − CGx 1.900 |

**横航向静导数（Mx/My/Mz/CY 量纲表，α=0、β=±5°~±15° 线性拟合，qSb=½ρV²Sb, V=48.611）：**

| 系数 | 值 /rad | 原 stock | 偏差倍数 | 拟合出处 |
|------|---------|----------|----------|----------|
| Clβ（c_l_b） | **−0.093** | −0.12 | 1.3× | Mx(β=−5…+5, α=0) |
| Cnβ（c_n_b） | **+0.015** | +0.25 | **stock 夸大 16×** | Mz 表；β=10° 直算 0.0084，±15° 拟合 0.015 |
| CYβ（c_y_b） | **−0.44** | −0.98 | stock 夸大 2.2× | CY 表（α=0） |

Cnβ 自洽性核对：Cnβ ≈ CYβ × (垂尾尾臂/翼展) → 0.44×0.03~0.1 量级 ✓；stock 0.25 相当于大垂尾通航机，与 DF-200 小垂尾不符。

**动导数（动导数 sheet，8 项中已用）：**

| 系数 | 值 | 备注 |
|------|-----|------|
| Clp（c_l_p） | **−0.5873** | AVL 真值。169 曾减半至 −0.3 防 Euler 发散，208 证明真值下无发散 |
| Cnr（c_n_r） | −0.065 | 比 stock −1.0 弱 15×；荷兰滚欠阻尼是数据真实特性 |
| Cmq | −19.287 | 纵向阻尼主力 |
| Clr / Cnp / Cmα̇ / Cnβ̇ | 未提供 | SITL 取 0；α̇/β̇ 洗流延迟项已向数据方列为缺口 |

**舵效（elevator/rudder/aileron 三张 δ 扫描表，α=0、β=0 列；力矩归一 My/(qS·c)、Mx/Mz/(qS·b)）：**

| 系数 | 值 /rad | 历史/stock | 拟合细节 |
|------|---------|------------|----------|
| Clδa（c_l_deltaa） | **+0.25** | 曾用 0.091（早拟合）→0.15（155 折中） | \|δ\|≤10° 线性段 0.25；25° 饱和至 0.20（非完全线性） |
| Cmδe（c_m_deltae） | **−1.21** | 曾用 0.42 = **弱 3 倍**，是 181 AS60 340Nm 拉不住的真因（当时误归因 CGOffset） | 对称拟合 ±5…±25°，含 Cm0 基线扣除 |
| Cnδr（c_n_deltar） | **−0.069** | stock −0.1 偏强 45% | \|δ\|=5°:0.063、25°:0.068，几乎全线性 |
| CYδr / Clδr | **0 / 0** | stock −0.2/−0.037 无数据依据 | rudder 表 CY/Cl≈0 → **V 尾纯差动**的 CFD 实现 |

**V 尾解读**：elevator 表 Cnδ≈0、rudder 表 Cmδ≈0 → 对方按「升降=左右同向、方向=左右差动」算的独立表，混合比已解耦，直接可用；需向对方确认 V 尾安装角与 ±25° 的定义（舵偏 or 舵机行程）。

### 4.2 与数据方核对清单（遗留）

1. ① 巡航行 Y=−1315 应为 **+1315**（右），已按垂起行取值
2. 动导数缺 α̇/β̇ 项与归一化说明（AVL 已除 b/2V 需确认）
3. 低速气动未覆盖：Re 临界区估计 **0.5–1.5×10⁶ ↔ 10–30 m/s**（正覆盖 WAIT 段）；已请求 Re=1.2e6（25 m/s）collapse 校核点
4. CD0 定义为「表最小 CD」在 α≈−2°（近零升迎角），与 `CD=CD0+CL²/(πeAR)` 有 ~0.0003 定义差，接受

首个全严格气动 + 断点门控成功飞次：WAIT 57.5 s（roll ±0.2°/pitch ±1.3°）、TIMER 4.5 s、FW 巡航 roll 跟踪 1.3°/pitch 0.12°。三个历史风险（Clp 发散 / aileron 锁死 / elevator 过冲）均未复现——large-I 调参 + Clp 真值阻尼 + 舵效恢复后，此前为隔离问题做的折中全部可退。

### 7.1 倾转默认应垂直

APM 约定：`current_tilt = 0` → **垂直向上**；`1` → 前飞。  
`Q_OPTIONS` bit21 `DISARMED_TILT_UP`：未解锁且非 MANUAL 时把 tilt slew 到 **0**。  
统一倾转通道 `SERVO13/14_FUNCTION=41`（`k_motor_tilt`）：scaled≈0 → PWM≈`SERVO*_MIN`（1000）。

`00000025` 已验证：全程 `TILT.Tilt=0`，tilt PWM=`1000/1000`，**不是前飞角问题**。  
SITL `df200_motors` 的 `pitch_min/max=-90…+10` 与「PWM MIN≈向上」一致；勿随意 `SERVO*_REVERSED=1`，除非确认物理/可视化反了。

数据库口径「垂起 0°、前飞 90°」与 APM `current_tilt*90` 一致。

### 7.2 350 kg 增益建议表（已写入 parm）

背景：`00000025` 推力够（爬到 ~5 m），但 stock 小多旋翼增益 + AUTO takeoff 导致 Pitch/Roll 发散。

| `Q_A_ANG_YAW_P` | 4.5 | **2.5** | |

## 9. `00000025` / `00000026` 复盘

| Log | 模式 | 现象 | 参数是否新增益 |
|-----|------|------|----------------|
| 00000025 | AUTO takeoff | 爬到 ~5 m，Pitch/Roll 发散砸地 | 否（stock） |
| 00000026 | QHOVER→AUTO takeoff | 新增益已加载；仍爬到 ~3 m 后 **Pitch→+60°** 砸地 | 是 |

`00000026` 关键证据：

- 新增益生效：`Q_A_RAT_PIT_P=0.04`、`Q_ANGLE_MAX=2000`、`Q_WP_SPEED_UP=100`
- 倾转一直垂直：`TILT=0`，PWM `1000/1000`
- 起飞瞬间电机几乎均分（`mott≈0.67×8`），但 **Pitch 速率持续为正**，控制器 `PDes` 打满低头仍拉不回来 → 更像**常值抬头干扰力矩**，不是单纯增益不够

根因（几何 × SITL 倾转约定）：

1. `df200_motors` / JT20 同款 `pitch_min/max = 10, -90`：PWM=1000 时 SITL 电机 pitch = **+10°**（近垂直但略前倾），内四推力有 body-X 分量  
2. 原 json 用了数据库真实 **Z**（前倾转 z≈−0.41，后倾转 z≈−0.94）  
3. 力矩 `My = z·Fx − x·Fz`：前后 `x·Fz` 大致抵消，但 **`z·Fx` 同号相加** → 悬停等推力约 **My≈220 N·m ≈ 27°/s²** 持续抬头  

修法：与 `jt20.json` 一样，**电机位置 Z 全部置 0**（XY 仍用数据库）。Z=0 后同条件残余 My 降到可忽略量级。已改 `Tools/autotest/models/df200.json`。

### 11.4 机理：为什么小扰动会长成发散（物理 chain）

```text
① 小偏航扰动 δr（种子：数值噪声 / ~6 Nm 残余反扭）
② 机头偏 -> 气流斜吹机身侧面 -> 侧滑 β 出现
③ β 的两个静力矩：
   Clβ·β：左右机翼迎角不对称 -> 左右升力差 -> 滚转力矩
   Cnβ·β：垂尾风向标力 -> 把机头往回拉，但带惯性 -> 过冲 -> β 反号
   （荷兰滚振荡的雏形）
④ 轴间互耦（互相喂能量）：
   Clr·r：偏航旋转使左右机翼相对空速不同 -> 滚转力矩
   Cnp·p：滚转使左右机翼迎角不同 -> 偏航力矩
⑤ 能量博弈：
   供能：③的过冲 + ④的互耦
   耗能：Clp·p、Cnr·r（气动阻尼）+ 旋翼差动 + 舵面
   本构型下：旋翼差动被 Lua 收掉（R≈0）、舵面气动=0
   -> 只剩机翼自身阻尼，半倾转滑流又增强耦合
   -> 每振荡一轮净增能量 -> 振幅指数增长
```

为什么 149 把种子削到几个 Nm 仍炸：**发散不取决于种子大小，取决于阻尼/耦合的净符号**。种子只决定起振时刻，不决定是否发散。

### 11.6 附：垂起反复失败的教训（yaw 权威 vs I）

### 11.7 横航向气动导数速查（符号 / 物理意义 / 在本项目的角色）

> 记法：`C_XY` = 「Y 引起 X 轴力矩」的导数。X∈{l 滚转, m 俯仰, n 偏航}，Y∈{β 侧滑角, p 滚转速率, r 偏航速率, δ 舵偏}。  
> SITL 对应字段见 `SIM_Plane.h` `coefficient`（`c_l_b`、`c_n_r` 等）；公式实现 `SIM_Plane.cpp` getTorque（la/ma/na 三行）。

#### 侧滑静稳定项（β -> 力矩，「弹簧」）

|------|-----------|----------|----------|----------|------------------|

### 11.10 158–162：TIMER 段突跳的根因定位——`position%gyro` + `calc_thrust` 平方正反馈

> 本节是本次调研的核心结论。配套日志 `/tmp/df200_rotor.log`（含逐电机 `cmd/Mxi/Tzi/Txi/velin/thrmag/mvelx/mvely/mvelz`）、`/tmp/df200_mix.log`（混控器内部量）、`/tmp/df200_aero.log`（含 RPY/Alt）。

#### 现象（158–161，同一位置同一形态）

`AIRSPEED_MIN=45`、`c_l_deltaa=0.15`、Lua floors 全 0。每趟均在 TIMER 段 **tilt≈38°、AS≈49** 出现 `RATE.R`（159 是 `p`，160/161 是 `r`）**一步跳到 ±34.9 rad/s（饱和）**，0.2–3 s 内坠地。`Q_TRANSITION_MS` 10→32767 无效，说明不是「油门衰减太快」。

#### 正反馈链（161 用逐电机数据逐帧钉死）

```text
① 任意小 p/r（数值噪声，~0.02 rad/s）
② position%gyro: position × gyro 给左右电机反向 mvelz
   （roll 的 p 经 y 坐标 → Z 向速度；yaw 的 r 经 x 坐标 → Y 向速度）
   161 数据: p=0.024 时 mvelz 左右差 0.4；p=34.9 时差 91.8
③ mvelz 差 → projected(thrust_vector) → velin 左右分裂
   tilt 后 thrust_vector 倾斜，投影放大左右差异
④ velin²差 → calc_thrust 平方差 → thrmag 左右不对称
⑤ thrmag 不对称 → 几何 Mx/Mz = Σ(r×F) 不对消 → 净力矩（与 p/r 同号！）
⑥ 同号力矩 → 角加速度增大 → p/r 增大 → 回到 ①
⑦ 增益 > 1 → 0.2 秒指数饱和
```

#### 为什么「tilt 38°+高速才炸」——`calc_thrust` 平方差放大器

`calc_thrust`（`SIM_Motor.cpp:321`）：

```text
thrmag = 0.5·ρ·A·(Vout² - velin²)
```

对左右同 cmd 电机，`Vout` 相同，推力差：

```text
d_thrmag = 0.5·ρ·A·(velin_M3² - velin_M1²)
         = 0.5·ρ·A · d_velin · (velin_M1 + velin_M3)
                          └─ 放大器增益，与 velin 之和成正比 ─┘
```

| 工况 | velin | (v1+v3) | 放大倍数 | velin 差 0.3 → 推力差 |
|------|-------|---------|----------|----------------------|
| 悬停（tilt=0，AS=0） | ~0 | ~0 | **≈0** | 0 N（不放大，稳定） |
| 低速（tilt=30，AS=20） | ~5 | ~10 | ~8 | 2.4 N（小，可能稳定） |
| **高速（tilt=38，AS=49）** | **~50** | **~100** | **~81** | **24 N（大！增益>1，发散）** |

**放大器在高速时才被「打开」**：悬停 velin≈0、增益≈0，d_velin 不放大；高速 velin≈50、增益≈81，环路增益跨过 1 → 正反馈。这就是「之前机体旋转也不大却没炸，到 tilt 38°+高速就炸」的原因——不是 `position%gyro` 变大了，是放大器在高速被打开。

#### 极性翻转（155–161 数据）

```text
roll_t<0（控制器想产生 +Mx 纠正 p<0）
但实际 Mtot_x<0（与 p<0 同号，助纣）
→ 物理链产出的力矩极性和控制器期望的相反
→ 越纠正越发散
```

矩阵对称、期望正确、无饱和（`rpy_scale=1, lim=0000`），但**矩阵之后的 `calc_thrust`+几何把极性翻了**——不是矩阵问题，是 SITL 桨模型在 tilt+高速的数值正反馈。

#### 162 隔离试验（根因证实）

改动：`SIM_Frame.cpp` 在 DF-200、AS≥25 时把传给 `Motor::calculate_forces` 的 `gyro` 置 0（切断 `position%gyro` 这条路径）。其余不变。

```text
161: position%gyro 正常 -> tilt 38° AS 49 炸（mvelz 左右 ±91 分裂）
162: position%gyro 置 0 -> mvelz 全 0.9（不分裂）-> 过墙 -> FW done ✓
```

**切断 `position%gyro` 就不炸 → 这条正反馈链就是 TIMER 段突跳的根因，证实。**

> 注：`position%gyro` 置 0 是物理不真实的（机体旋转时桨尖确实有线速度），仅为诊断。真实飞机里这个反馈被阻尼压住，SITL 这里阻尼弱（舵面小、旋翼差动被 Lua 收掉）+ 放大器太强（`calc_thrust` 平方差高速增益 81），环路增益 >1。

#### 真正的修法方向

1. **限制 `calc_thrust` 对 velin 差异的放大**：velin 钳位/衰减平方差，降低高速增益
2. **TIMER 段旋翼纯集体油门**（tilt>30° 强制抹平差动）：不让旋翼参与姿态，从源头消正反馈
3. **保留 `position%gyro` 但限制它对推力的影响**：DF-200 高速段降低 velin 权重
4. 不要靠 `position%gyro` 置 0 当最终解（诊断用）

### 11.11 162 固定翼阶段问题：静稳定缺失 + 控制发散

162 进 `FW done` 后（312–336 s）固定翼飞行质量差：

| 现象 | 数据 |
|------|------|
| Roll 振荡发散 | DesRoll≈-7°，实际 ±10→±15→328s 后 ±170°，Ail 打满 1272 |
| Pitch 持续抬头 | DesPitch 15→0°，实际 +1→+29°，Elev 打到 989 |
| 偏航 r 恒定 52.4 | Yout=0 全程（yaw 环疑似未正确接管） |

根因：为 TIMER 突跳隔离试验关掉的气动参数**还在 0**，固定翼阶段缺静稳定和阻尼：

| 参数 | 当前 | 固定翼需要 | 影响 |
|------|------|------------|------|
| `c_l_b`（Clβ 上反角） | 0 | **-0.12（stock）** | 滚转静稳定，没它 roll 不回正 |
| `c_l_r`（Clr 互耦） | 0 | +0.14（stock） | 偏航→滚转，影响小 |
| `c_n_p`（Cnp 互耦） | 0 | +0.022（stock） | 滚转→偏航，影响小 |
| `c_n_r`（Cnr 阻尼） | -0.065（Excel） | 可试 stock -1.0 | 偏航阻尼，-0.065 太弱 |

`c_l_b=0` 是固定翼 Roll 发散的主因——没有上反角，滚转一扰动不回正，靠副翼（0.15）压不住。

#### 修法（162 后）

1. **恢复 `c_l_b=-0.12`（上反角）**：固定翼滚转静稳定，最优先
2. `c_l_r=+0.14`、`c_n_p=+0.022`：恢复横航向互耦（固定翼正常飞行需要）
3. `c_n_r` 试 stock -1.0：偏航阻尼强 15 倍，压 yaw 振荡
4. 这三项恢复后**可能重新触发 TIMER 突跳**（互耦回来了）——但 TIMER 段已被 `position%gyro` 隔离解决，互耦在固定翼阶段是必要的

> 矛盾：固定翼要 `c_l_b/c_l_r/c_n_p` 恢复，但 TIMER 段的根因是 `position%gyro`（已用隔离解决），不是这些互耦项。所以恢复它们对 TIMER 无影响（162 已证 position%gyro 是根因），对固定翼有利。可以放心恢复。
