## 4. 与 docx 电机表（`df200_motor_data.md`）的对比

> 2026-10-30 更新：换表已落地（`SIM_MotorTable.h`），本节结论更新为最终状态。

| 项目 | 本组 RY60 实测 | docx 表0（60in 静态） | 本组 DH40 实测 | docx 表1 v0（40in 静态） |
|------|---------------|----------------------|----------------|--------------------------|
| 峰值拉力/桨 | 1109 N @ ~3100 rpm | 1379 N @ 3181 rpm | 385 N @ ~3050 rpm | 374.2 N @ 3000 rpm（"拉力(g)"列实为 N） |
| 峰值功率/桨 | 26.7 kW（电功率） | 32.0 kW | 11.2 kW（电功率） | 10.1 kW @3000rpm |
| 峰值扭矩/桨 | 74.4 N·m | 96.2 N·m | 32.8 N·m | 31.4 N·m @3000rpm |
| 母线电压 | ~397 V | ~396 V | ~398 V | — |

**对比结论（换表后最终版）**：

1. **60in：已换用本组 165M20 实测表**。docx 表0 属另一套未知电机（峰值偏 20%），已从 `SIM_MotorTable.h` 弃用。docx 表0 的"1551 rpm 悬停点"实为表最小测点（278 N/桨），不是悬停点——旧功率走廊的"悬停 12.2 kW"结论作废，重算见 `df200_hover_corridor_bench_derivation.md` §2.1（380 kg 悬停 ~2458 rpm / 75.2 kW，8 桨分摊，外桨占 72%）。
2. **40in：单位问题已破案，docx 表1 数值无需改**。DH40 台架 3000 rpm 静态推力 ~380 N，docx 表1 v0 同转速"拉力"374.22——比值 0.98；扭矩列比值 1.03、功率列比值 0.96 同步吻合，证明是同一套动力系统。**docx 表1"拉力(g)"列实际单位是 N**。`SIM_MotorTable.h` 的 prop40 代码数值本来就是原值（N），错的是 `df200_motor_data.md` 的换算描述（已修正）；原"19.1 kW 超出台架能力"的疑点不成立（docx v50@4000rpm 点超出 135M10 台架扫描范围 3050 rpm，不冲突）。
3. 随换表同步落地的关联改动：`SIM_Motor.cpp:74` cmd→rpm 峰值常数 3181/4200 → **3150/3050**（按两组台架有效扫描上限）；`df200_power_analysis.py` 表数据同步。
4. 本组测试环境温度低（绕组温度 −11~0 °C），低温下电机效率略偏高，与常温飞行数据对比时注意。

## 5. 数据质量与局限

| 局限 | 说明 |
|------|------|
| 时间戳非单调 | TIME(ms) 列存在乱序/分段，分箱统计按数据行处理，不影响均值 |
| 传感器毛刺 | 存在 rpm=40866、rpm=6、拉力为负等无效行，已按 §1 过滤条件剔除 |
| 135M10-2 前段电流异常 | 10–20% 油门区间出现负电流（−0.13 A），为传感器零漂，分箱均值已稀释 |
| 165M20-2/-3 低油门段 rpm 乱跳 | 3979/3662/2631 rpm 等异常点，起转阶段测速不稳，已过滤 |
| 静态测试 | 无来流，倾转桨需配合风洞表（docx 表2）才有完整特性 |
| 低温环境 | 绕组 −11~0 °C，红外 29–35 °C，效率读数偏乐观 |
| 单桨测试 | 多桨干扰（机身流场）未包含，整机推力 < 单桨之和 × 桨数 |
